# Record the design choice that looks like a defect

A deliberate choice a reader would otherwise take for a mistake — an unusual default, a flow
that is long on purpose, a deliberately quiet colour, a step with no way back — is recorded
where someone reviewing that surface will find it: the design document, the decision record, or
a line beside the code that implements it. Design intent leaves no trace in the code that
expresses it, so an unrecorded choice is indistinguishable from an oversight and the next
reviewer will file it as one.
