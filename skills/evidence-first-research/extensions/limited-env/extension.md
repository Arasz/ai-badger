# evidence-first-research extension: limited-env

At the start of each investigation topic, search available project memory before repository code or external sources. Use the canonical project identity and the project's configured memory scope. Inspect the source references for relevant entries. Repeat the memory search when the topic changes.

If memory search is unavailable, say so once and continue with sources permitted by the repository and environment. Do not claim that memory was checked. Use direct command output as evidence; do not wait for a hook-captured hash, transcript, injected context, or automatic research observer. No hook enforces this procedure.
