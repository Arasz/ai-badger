# how-to — task-oriented, the reader's goal

A how-to answers "I need to do X" for someone who already knows what X is and why they want it.
It assumes competence and skips motivation. Filenames start with an imperative verb
(`seed-a-partition.md`, not `partition-seeding.md`).

If the reader does not yet know what they want, they need `../tutorials/`.
If they need to look a fact up rather than follow steps, they need `../reference/`.
