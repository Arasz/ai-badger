# assets — images and diagrams, no quadrant

Binary and vector artwork referenced by documents elsewhere in this tree. Assets belong to no
Diátaxis quadrant: the same diagram can serve a tutorial and a reference page, so it lives here
once and both link it.

Assets are frozen against reformatting by rule 6 of the freeze list (not `.md`). They are moved
only when nothing pins their path.
