## Rulings (supersedes rev 1 where different; new rulings marked)

- **C1 (amended by CR-M1, CR-M3, QA-9):** Global-watermark prefilter. Tick = one read-only `SELECT COALESCE(MAX(id),0) FROM messages` + `fs.statSync` identity (+`COUNT(*)` in the same query, CR-N3) + per-session in-memory fingerprint `{maxId, count, dev, ino}`. **Skip only when**: fingerprint exactly equals last clean probe (MAX **and** COUNT equality), file identity unchanged, last spawn younger than **60 s** (CR-M2 max-skip-staleness), and DB file exists — `ENOENT` ⇒ sound skip, never a spawn (QA-9: a read-only probe must not create the user DB as a side effect). Everything else ⇒ spawn. Errors of every kind (stat, probe, resolver) ⇒ spawn (fail-open). **Watermark advances only**: to the **tick-time fingerprint captured before the spawn** (CR-M3 — never re-read post-spawn), on a parseable delivery outcome **that does not carry the failure marker** (CR-M1); a failure-marked or error/timeout outcome leaves it stale (retry next tick, notice-latched). **First tick of a session always spawns** (watermark null). The seams' decorator shares every one of these rules (CR-N4a).
- **C2 (unchanged, construction pinned per QA-3/QA-11):** wake classification lives in the Python txn. `deliver_for_session` **return shape changes to `(messages, summary)`** where `summary = {"addressed": n, "broadcast": m}` counts the delivered batch only (post-gate, post-cap, post-R2; gated-off/own rows count 0; D7 leg-not-run counts 0) — the 29 existing test call sites are amended deliberately in one named commit (QA-3). `_read_addressed` gains the target columns it needs (QA-11; D6 EXPLAIN gate re-covers). `message_delivery_hook.py` merges the summary into the response **in `_deliver`, after `build_response`** — the existing exact-key-set pin at `tests/test_message_delivery_hook.py:210` stays green; B6 pins the full wire shape at the `guarded_main` level. Field name `hookSpecificOutput.aiBadgerBus`; a test pins it never occupies host-acted keys (`decision`/`continue`/`stopReason`/`suppressOutput`) (CR-N6).
- **C2b (new, CR-M1):** the hook's fail-open path becomes wire-distinguishable: on `guarded_main` catching, the response is `{"hookSpecificOutput": {"aiBadgerBus": {"error": true}}}` (exit 0, fail-open unchanged, log line unchanged shape + C8 message). Clean-empty stays `{}`. This is what makes the watermark advance rule sound.
- **C3 (unchanged; verified against pi 0.84.4 source by CR-N1):** idle + broadcast-only mail under `addressed` ⇒ consume + inject without wake: `sendMessage(doc, {deliverAs:"steer", triggerTurn:false})` — appended without a turn (`_appendCustomMessage`), displayed, enters LLM context next turn. Residual (consume-then-lose) recorded in ADR.
- **C4 (new ruling, QA-4):** **streaming + broadcast-only under `addressed`** ⇒ consume + `{deliverAs:"steer"}`, no `triggerTurn` (C3-consistent; the txn consumed it mid-stream, deferral is unreachable for timer-consumed mail).
- **C5 (file layout, unchanged):** `bus-prefilter.ts` (pure) + `bus-store.ts` (I/O port, injected — CR-N5iii: bun suites never touch the real user DB nor spawn the real hook); `publish.ts` `ADAPTER_FILES` gains both names.
- **C6 (unchanged):** push path keys on `ctx.sessionManager.getSessionId()` only.
- **C7 (amended, CR-N4b):** `AI_BADGER_PI_BUS_WAKE=off` ⇒ timer never armed; **seam-spawn prefilter gating stays ON** (spawn economy is wake-policy-independent; delivery outcomes unchanged — skip happens only when the txn would return nothing).
- **C8 (unchanged):** `record_hook_failure` logs the sanitized exception message (payload-derived substrings never reach the log); `guarded_main` still fails open (B5).
- **C9 (new, CR-S1/QA-2):** the wrap-guard's true premise: `messages.id` is `AUTOINCREMENT` — rowid reuse cannot occur through the store's own writes. The guard (`cursor_id > COALESCE(MAX(id),0)` inside the txn ⇒ treat the session as **cursor-less for this read**: 30-min gate + 16-cap + leg-scoped landing re-apply — never a plain reset onto the live-read path) is retained as cheap insurance for DB replacement/restore states, with the honest boundary: `cursor == MAX(id)` post-restore is indistinguishable from caught-up without an epoch — ADR carries it as a residual, not "self-heals".
- **C10 (new, CR-S2):** missing-summary fallback: `additionalContext` present + `aiBadgerBus` absent (old hook copies on un-refreshed projects) ⇒ treat as **addressed** (wake) — fail-open toward the headline feature; `{}` + absent ⇒ empty. Den-refresh coordination for hook copies recorded alongside the project-id backfill note.
- **C11 (new, CR-S3):** routing consults `ctx.isIdle()` as the authority with `agent_start`/`agent_end` flags as hints; the compacting flag is timestamped and expires (10 min) and is also cleared by `agent_start`; `session_before_compact` sets, `session_compact` **and** `session_compact_failed` clear (owning test A10, QA-6).
