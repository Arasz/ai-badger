## The single most important test the plan is missing

`tests/test_archify_vendor.py::test_revendor_refuses_a_forged_packet_even_when_the_manifest_agrees`.

It is the only test that can falsify the plan's origin claim. Offline `--check` honestly proves
internal consistency only; the plan's answer to "these bytes are upstream v2.16.0" is the release-asset
sha, and every proposed test around it either re-hashes the manifest against the disk or checks the
manifest against itself. The missing case is the adversarial one: a zip whose sha matches a tampered
`vendor.json`, and a `vendor.json` whose recorded asset sha was derived from the same forged pair.
The test writes both, runs `--revendor`, and requires exit non-zero before any write — which forces
the implementation to hold the v2.16.0 literal `4c59fa65…` somewhere that regenerating `vendor.json`
cannot overwrite. Without it, the provenance gate is self-signed, and that is the exact class of
false confidence this plan exists to avoid. (Second in line: the node <18 quadrant, QA-8.)

## Verdict on test honesty

The test thinking here is above average for a plan: hashes are re-derived with stdlib rather than
the generator, the upstream commit is pinned as a literal, planted-drift cases are named, the node
skip is called out rather than hidden, and the offline/origin distinction is stated in prose. But
three of the load-bearing checks are not yet falsifiable as written — the lint test passes on the
pre-change base (QA-1), the file-set oracle can be manifest-derived (QA-2), and the re-vendor sha
gate can be self-referential (QA-3) — and the one backstop for the node skip tests the catalog copy,
not the delivered copy whose join the python test drops (QA-5/QA-6). The node floor the plan's own
AC names has no case in the matrix (QA-8) and no field in the data model (QA-9). None of these is
fatal to the design; each is a small, concrete patch to tests that do not exist yet. Apply QA-1,
QA-3, QA-5, QA-7, QA-8 and QA-9 before the first test is written; the rest can land with the file.
As it stands, the suite would be green for the wrong reasons on exactly the two claims it exists to
protect: provenance and scaffold delivery.
