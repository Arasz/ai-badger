# limited-env hook writer audit

**Scope:** project scaffold outputs produced by ai-badger for Claude, Codex, Copilot, Hermes and Pi. The `limited-env` stack can stop the scaffold from adding ai-badger registrations and can remove registrations when their ownership is identifiable. It cannot disable hooks supplied independently by an administrator or another plugin. It does not prohibit repository scripts.

| Agent | Writer | Registration/output | Ownership evidence and cleanup | Stack control |
|---|---|---|---|---|
| Claude | `features/common/skills/welcome-ai-badger/scripts/hook_wiring.py::HookWiring.wire` | Writes project `.claude/settings.json` hook entries and `.ai-badger/hooks/hooks.json`. | `skill_script_id` recognizes ai-badger skill paths; merge prunes matching framework scripts while preserving unknown commands. The early return when Claude is deselected does not clean old project entries. | Yes, project output. |
| Claude | `features/claude/adjustments/adjust_tools.py` | Merges native tool handlers into `.claude/settings.json`. | `tool_hooks.is_ours` marks commands; adjustment declares `cleanupOnDeselection`. | Yes, project output. |
| Codex | `features/codex/adjustments/adjust_hooks.py` | Merges framework hooks into `.codex/hooks.json`; copies hook adapters into `.ai-badger/hooks/`. | `_ours` identifies framework script paths; config and adjustment support removal of owned entries. | Yes, project output. |
| Codex | `features/codex/adjustments/adjust_tools.py` | Merges native tool handlers into `.codex/hooks.json`. | `tool_hooks.is_ours` marks commands and `_merge` removes marked handlers; adjustment declares `cleanupOnDeselection`. | Yes, project output. |
| Copilot | `features/copilot/adjustments/adjust_hooks.py` | Writes `.github/hooks/ai-badger-hooks.json` and hook scripts under `.ai-badger/hooks/`. | The dedicated filename is ai-badger named. The limited-env deselection path removes only `.github/hooks/ai-badger-hooks.json`; unrelated files in `.github/hooks/` are preserved. | Yes, project output. |
| Copilot | `features/copilot/adjustments/adjust_tools.py` | Writes `.github/hooks/<tool>-rewrite.json`. | `_marked` checks that all handlers are `tool_hooks.is_ours`; stale marked files are removed, unmarked files are preserved. Adjustment declares `cleanupOnDeselection`. | Yes, project output. |
| Hermes | `features/hermes/adjustments/adjust_hooks.py` | Copies hook implementations to `.ai-badger/hooks/`; when installation is enabled, installs an auto-loaded plugin at `$HERMES_HOME/plugins/ai-badger/`. | Limited-env skips this adjustment, including project copies and user-global install. The installer refreshes owned files but does not disable or remove an already installed plugin. | Project copies and future user plugin install: yes. Existing user plugin is outside project cleanup. |
| Hermes | `features/hermes/adjustments/adjust_tools.py` | Prints an optional user-wide tool install command; it does not execute or write it. | No registration is written by this adjustment. | No registration to suppress. |
| Pi | `features/pi/adjustments/adjust_hooks.py` | Copies hook implementations to `.ai-badger/hooks/`; when installation is enabled, copies an auto-loaded extension to `~/.pi/agent/extensions/ai-badger/`. | Limited-env skips this adjustment, including project copies and user-global install. The adjustment does not remove an already installed user extension. | Project copies and future user extension install: yes. Existing user extension is outside project cleanup. |
| Pi | `features/pi/adjustments/adjust_tools.py` | Runs or proposes a tool-owned project extension according to tool configuration. | Tool owns its own extension; this adjustment is not an ai-badger hook writer. | No ai-badger registration to suppress. |

Independent Claude, Codex, Hermes and Pi plugins or extensions can register hooks at user scope. Administrator-managed hooks and hooks installed outside the scaffold are also beyond a project stack's authority. The tests must show that limited-env leaves these outside sources untouched and must not describe the stack as disabling them.

## Test contract

The behavior matrix covers selected and omitted stack, fresh scaffold and re-scaffold, and each agent's concrete output location. Re-scaffold fixtures seed an owned entry and an unrelated entry; the limited stack must remove only the owned project entry. Hermes and Pi user-global installation is exercised under a temporary home to prove limited-env does not install a new ai-badger plugin or extension. The existing user-global plugin state is not removed by project-scaffold tests.
