# work — dated records of work done, not documentation of how things are

A work record describes a moment: what was proposed, what was decided, what was reviewed, what
broke. It is true of its date and is never updated to stay current — that is what makes it a
record. Documentation of how the framework works today lives in the quadrants
(`../reference/`, `../explanation/`, `../how-to/`, `../tutorials/`); decisions that bind live in
`../adr/`.

Filenames are `YYYY-MM-DD-slug`. A file here without a date is a placement error.

This directory is deliberately *not* grouped into `plans/`, `research/`, `designs/`, `reviews/`
or `incidents/`. Kind is not a subject, and those five were tried and removed — see
`../adr/` and PR #111.
