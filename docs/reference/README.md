# reference — information looked up mid-task

Facts you consult while doing something else: field lists, schemas, command surfaces, catalogs.
Reference pages are read in fragments, never linearly, so they are organised for lookup rather
than for reading. Filenames are bare nouns (`signal-fields.md`, not `understanding-signals.md`).

If a page explains *why* something is shaped the way it is, it belongs in `../explanation/`.
If it walks the reader through doing a thing, it belongs in `../how-to/`.
