# 0.158.1 — the cross-stack reference scan skips vendored dependency trees

## What changed

`cross_stack_reference_gaps` (the C8 check) applies the existing `_is_vendored`
exemption to its rglob: a markdown file under `node_modules` is vendored
third-party documentation, not the stack's authored prose, so its tokens are
not dangling-pointer findings.

The trigger was real: `features/pi/node_modules/` (gitignored pi-adapter
dependencies) carries the pi-coding-agent's own `docs/skills.md`, and 0.158.0
shipping a skill named `code-review` turned that vendored token into a local
gate failure. CI (fresh checkout, no node_modules) never saw it; the local
pre-push lane did, and the check's blind spot was the honest defect.

`unschemad_feature_json` already used `_is_vendored`; the C8 rglob never had.
Tests pin both legs: an authored stack file naming a foreign artifact is
reported, the vendored copy is not.
