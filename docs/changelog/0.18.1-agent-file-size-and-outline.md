# 0.18.1 — smaller agent files, one document outline

Scaffolded `CLAUDE.md` was over the task skill's line budget (130 lines against a limit of
110). Two thirds of it was injected content that did not need to be that long, and the
embedded invariants broke the document outline.

## Changed

**The `code-review-graph` instruction block: 38 → 12 lines.** It carried a 13-line table
restating each tool's own schema description, plus a generic workflow list. An agent already
receives every tool's description, and the MCP server injects its own instructions at session
start, so the table cost tokens in every session to say nothing new. What remains is the part
nothing else states: that graph tools come before Grep/Glob/Read, and where to start.

Effect on generated files:

| File | Before | After |
|---|---|---|
| `CLAUDE.md` | 130 lines | 102 |
| `HERMES.md` / `.hermes.md` | 165 lines | 137 |

## Fixed

**Invariant snippets no longer emit H1s inside the agent file.** `collect_invariants()`
embedded each snippet verbatim under `## Non-negotiable invariants`, so a file with nine
invariants carried ten competing H1s. Headings are now demoted two levels at render time via
`demote_headings()`, which skips fenced code so a `# comment` in a shell block is not mistaken
for a heading. The standalone copies under `.ai-badger/invariants/` keep their original H1 —
they are documents in their own right.

**`features/angular/invariants/signal-state-discipline.md` started at `##`** while all 18
others started at `#`, so it rendered one level deeper than its siblings. Normalized.

## Tests

- `test_catalog_tool_instructions_stay_within_a_line_budget` — fails any catalog tool whose
  `instructions` exceed 15 lines, naming the offender. Stops the manuals from growing back.
- `test_invariant_rendering.py` — heading demotion, fenced-code safety, `#5`-is-not-a-heading,
  and a guard that every invariant source leads with a single `# `.

## Note

Projects already scaffolded need `den-refresh` to pick this up; the change is to what the
scaffold emits, not a migration of existing files.
