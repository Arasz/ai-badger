# 0.13.1 — scaffold re-runs stop appending duplicate hooks

Fix duplicate hooks appended to `.claude/settings.json` on scaffold re-run.

The `wire_hooks` merge logic checked each inner hook command individually for
duplicates but appended the entire outer entry. When an entry contained multiple
hooks and only some were new, the whole entry was re-added — duplicating hooks
that already existed in other entries.

Extracted `merge_hooks()` as a standalone, testable function. The new logic
builds a set of registered commands up-front, filters new entries to only
genuinely new hooks, and appends only the filtered subset.
