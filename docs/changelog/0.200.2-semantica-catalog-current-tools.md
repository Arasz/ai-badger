# 0.200.2 — semantica catalog covers the tools 0.6.8 serves

**Patch** (fix) · **Date:** 2026-10-18

- **semantica catalog adds `query_graph`, `update_node` and `delete_node`.** The 0.200.1 catalog
  was built against semantica 0.6.6, which serves 12 tools. The prerequisite installs semantica
  unpinned, and PyPI's latest, 0.6.8, serves 15. Its tools/list, enumerated live on 2026-10-18,
  matches the v0.7.0 `docs/reference/mcp_server.md`. The three tools 0.6.6 lacks fell to a
  heuristic `general` tag, so `mcp-index validate` failed on a fresh install. They now carry
  curated intents and tags.
- **`get_graph_analytics` keeps its warning.** It still fails on 0.6.8 with the same PageRank
  error.
- The semantica catalog test now asserts the exact 15-name set instead of a count. The install
  stays unpinned. The verified versions (0.6.6, 0.6.8, v0.7.0 docs) are recorded in that test and
  in this entry, because `meta.json`'s schema allows no extra fields and `server.md` is near its
  500-character budget.
