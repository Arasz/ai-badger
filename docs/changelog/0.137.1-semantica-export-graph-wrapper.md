# 0.137.1 — semantica export_graph wrapper fix

**Patch release** — fixes the upstream semantica v0.6.5 export_graph bug without requiring an upstream upgrade.

## What changed

- **`semantica_mcp_wrapper.py`**: new wrapper script that monkeypatches `_tool_export_graph`'s json branch to use a tempfile (upstream calls `JSONExporter().export(graph)` without the required `file_path`)
- **`check.py`**: `export_graph_works()` now tries the wrapper as a fallback when the native probe returns an error
- **`engine/requirements.txt`**: semantica declared as optional dependency (satisfies deps-guard)
- **Test**: wrapper fallback path verified with mocks

## Root cause

Upstream semantica v0.6.5-0.6.6: `_tool_export_graph` calls `JSONExporter().export(graph)` but `export()` requires `file_path` and writes to disk (returns `None`). Every json-format export fails with `TypeError`. The RDF/json-ld branches work fine.

## Verification

- Probe: `_patched_tool_export_graph({'format': 'json'})` returns `{"format": "json", "data": ...}`
- Tests: 28 passed (27 existing + 1 new wrapper fallback test)
