# 0.215.0 — decisions are recorded before they are built, in the project's own format

**Minor** (additive: one skill, one invariant, one task-loop step) · **Date:** 2026-10-23

## New

- **`decision-record` skill** (`features/common/skills/decision-record/`, `scope: default`).
  `scripts/detect_formats.py` reads the tree for an ADR log: a numbered record in an
  `adr`/`adrs`/`decisions` folder, or a folder declared by `.adr-dir` (adr-tools) or
  `.log4brains.yml`. It also looks for spec frameworks (`openspec/`, `.specify/`, `.kiro/specs/`) and
  reports which of `openspec`, `specify`, `adr` and `log4brains` are on PATH. The skill then
  writes into whatever the tree shows. Where there is both a log and a spec framework, it writes a linked
  pair: requirements in the spec change, rationale in the ADR. Where there is neither, it writes a MADR 4 minimal record in
  `docs/decisions/`. A CLI on PATH never chooses the format. It only decides whether the
  record is written through it, and nothing is initialised or installed.
- **`record-decisions` invariant.** A change that adds a feature or meaningfully changes how
  something works gets a decision record before implementation. Bug fixes, refactors with no
  behaviour change, and docs are exempt.

## Changed

- **`task` loop.** Both loops gain a `decision record` step between plan review and
  implementation, plus a verification-checklist item.
- **`status-report`.** The printed loop line includes the new step. A new test ties that
  line to the task skill's low-effort loop, so the next step added to one cannot miss the other.

Detection is hardened against what an independent review found:
- A marker that points outside the project, or that cannot be read, becomes a `warnings` entry
  instead of a write target or a crash.
- A date-named log (log4brains `20240101-…`, `2024-01-01-…`) reports `naming: date` and no
  `next` number.
- Symlinked log folders are followed, with a loop guard.
- `.github`/`.gitlab` are searched, and other hidden folders (framework state, worktrees) are not.
- Declared paths are normalised before dedup.
