# 0.39.1 — the documentation describes the product, not the work that produced it

`docs/` had become two trees sharing a directory. One documented ai-badger. The other documented
building ai-badger: plans, session checkpoints, waves, reviews, audits, incident post-mortems,
research passes and design documents whose feature had long since shipped. Thirty-two of the
fifty-one non-changelog documents were the second kind, and `docs/index.md` had grown four
sections — "Design records", "Audits and post-mortems", "Work in flight", "Historical" — that
existed only to index them.

Those thirty-two move to `.tmp/`, which is gitignored. They stay on disk and they stay in git
history; they stop being something a reader has to triage. What remains is nineteen documents:
seven references, eleven ADRs and their index.

## What survived the move, and how it was chosen

The test was not "is this interesting" but "would a reader of the product documentation lose
something true". Every candidate was re-verified against the code at 0.39.0 before being carried
forward, and anything that could not be verified was dropped rather than copied.

- `framework-architecture.md` gains the shape `scaffold.py` actually has — one `Scaffolder`
  holding a `ScaffoldContext` plus six collaborators, shared state on the context and the one
  real dependency passed as a constructor argument. It also now states that proxy files were
  **dropped, not deferred**, and why.
- `hermes-claude-compatibility.md` gains the learned-skill sync contract: what triggers it,
  where it writes, what it refuses, and that reconciliation is opt-in. This was the largest
  loss the move would otherwise have caused — a shipped feature that writes into a consumer's
  repository, described in no document a reader could reach.
- `authoring-a-feature.md` gains the `mcp-servers.json` contract it had been
  forward-referencing without ever explaining, including that `targetAgents` validates but is
  read by no production code.
- `scripts.md` gains `call-behaviorist`: the audit log's location, its single-letter record
  format and why the keys are a budget, and that it is off by default and every enablement
  expires.
- `dictionary.md` records why Copilot hooks emit `bash` alone.
- `SECURITY.md` gains the audit log's ownership mode and line cap.

## Two claims the extraction found to be false

Reading thirty documents against the code is a review of the code's documentation, and it caught
two statements that had quietly stopped being true:

- `RELEASING.md` said the untagged-release check "is informational — it does not fail CI". That
  was true of the incident's original resolution and was superseded by 0.35.3, which made it
  return 1. `gates/release_guard.py:159` checks it before the diff.
- `SECURITY.md` said `unsafe_literals.py` matches three tracked files on fake fixture values.
  Two of the three were documents retired by this release. One remains.

## The records that cite what moved

ADRs and changelog entries link to the moved files. Neither may be rewritten — an ADR is
append-only under ADR-0001, and editing a past changelog entry falsifies what that release said.
Repairing those links would mean falsifying a record to satisfy a link checker.

The prefixes go in `.docs-guard-ignore` instead, which is what that file is for: *"Add one only
when the absence is correct."* `docs_guard.py` passes on 100 documents with every link, repo
path and changelog entry resolving.

## Source files stopped pointing at documents that no longer open

Twenty-one docstrings and comments across `features/`, `skills/` and `tests/` cited
`docs/design/…`, `docs/plans/…`, `docs/reviews/…` and `docs/proxy-files-spike.md` as provenance.
A pointer to a file the reader cannot open is worse than no pointer, and the minimal-comments
invariant asks for the contract rather than the provenance. They are gone, replaced by an ADR
citation only where one genuinely covers the ground.

## Upgrading

Nothing required. No shipped behaviour changed — this release touches documentation, comments
and docstrings only. If you had bookmarked a document under `docs/plans/`, `docs/reviews/`,
`docs/design/`, `docs/specs/`, `docs/research/`, `docs/archive/` or `docs/incidents/`,
`git log --diff-filter=D --name-only -- docs/` finds it.
