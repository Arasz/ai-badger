# 0.132.0 — playwright-mcp and browser-usage skill

Adds first-class browser automation support across all agents via the official Playwright MCP server
(`@playwright/mcp@latest`) and a universal `browser-usage` skill:

- `features/common/mcp/playwright/` — Playwright MCP server definition (`meta.json`, `server.md`, `tools.json` covering 24 browser automation tools).
- `features/common/stack-mcp.json` — `playwright` declared as a common MCP server (`npx -y @playwright/mcp@latest`), giving all agents access to structured accessibility snapshots and browser automation.
- `features/common/skills/browser-usage/SKILL.md` — universal skill (`scope: default`) detailing accessibility-tree snapshots, element interaction by reference tokens (`[ref=eN]`), multi-field form population, network monitoring/mocking, custom Playwright code execution (`browser_run_code_unsafe`), and headless/headed configuration patterns based on official Playwright MCP documentation.

Minor bump: adds a new common MCP server and universal skill to the framework catalog.
