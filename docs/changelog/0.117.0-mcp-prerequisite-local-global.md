# 0.117.0 — Structured Local and Global MCP Prerequisite Install Options

**Type:** MINOR
**Date:** 2026-08-13

## What Changed

### MCP Catalog Schema (`schemas/mcp-server.schema.json`)
- Extended `prerequisite` schema to support optional `local` and `global` objects with `summary`, `check`, `install`, `uv`, and `command` fields.

### MCP Server Catalog (`meta.json` Entries & Conversion Script)
- Added `tooling/convert_mcp_prerequisites.py` script to convert MCP catalog `meta.json` entries to include structured `local` and `global` installation options.
- Updated Python-based MCP servers (`semantica`, `code-review-graph`, `hermes`) to specify `uv` commands for local (`uv venv` / `uv pip install`) and global (`uv tool install`) installation options.
- Converted .NET-based MCP servers (`ai-raccoon`, `aspire`) to include structured local (`dotnet tool install --local`) and global (`dotnet tool install -g`) installation options.
- Updated `mcp_tools.py` prerequisite reporting to output `local:` and `global:` install commands when available.
