# v0.141.0 — pi agent registration and feature directory (2026-08-28)

Adds pi as a fourth supported agent in the ai-badger framework, including
full registration, adjustments, and feature directory.

## Registration

- `AGENT_NAMES` in `engine/badger_lib.py` adds `"pi"` alongside claude,
  copilot, hermes
- All 6 schema enums (`config`, `agents`, `manifest`, `skills-source`,
  `stack-mcp`, `support`) accept `"pi"`
- `detect.py` detects `.pi/` directory in repo or `~/.pi/` in user scope
- `test_three_agent_scope.py` updated to assert pi presence
- `features/common/support.json` gains full pi capability matrix

## Feature directory (`features/pi/`)

- `stack.json` — detection signals and commands
- `scaffolding.json` — AGENTS.override.md template delivery
- `adjustments/adjustment.json` — 4 adjustment scripts
- `adjustments/adjust_mcp.py` — map .mcp.json to pi-mcp-tools settings format
- `adjustments/adjust_hooks.py` — install pi extension hooks (user scope)
- `adjustments/adjust_task.py` — install pi session source for task tracker
- `adjustments/adjust_cron.py` — install pi cron extension
- `adjustments/pi_session_source.py` — pi task tracker source
- `instructions/pi.instructions.md` — scoped instructions for pi agent
- `templates/AGENTS.override.md.tmpl` — pi context file template
- `cron/index.ts` + `package.json` — pi cron extension (Bun.cron() + launchd)
- `skills.json`, `skills-source.json`, `plugins-instructions.json`

## Task extension

- `features/common/skills/task/extensions/pi/` — task extension for pi
  with event mapping and delegation patterns

## Tests

- 14 tests in `tests/test_pi_adjustments.py` covering all 4 adjustments
  and the pi session source

## Housekeeping

- Exempt `features/*/cron/package.json` from schema coverage in `validate.py`
