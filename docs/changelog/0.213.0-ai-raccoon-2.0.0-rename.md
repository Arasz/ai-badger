# 0.213.0 — ai-raccoon 2.0.0 MCP tool rename

**Classification: Major (breaking)**

The framework now speaks the ai-raccoon **2.0.0** MCP tool names. ai-raccoon 2.0.0
renames its tool surface with **no aliases**: the old names disappear and the new
names take their place. Every framework reference — hooks, skill scripts, generated
agent instruction files, the MCP tool index and the docs — was updated to the new
names.

> **Release ordering:** ai-raccoon 2.0.0 must not ship before this framework change
> lands. Until it does, the framework's calls target names ai-raccoon 2.0.0 no longer
> serves.

## Scope of the change

- **Hooks** (`features/common/hooks/`, `features/common/skills/ai-raccoon-memory/scripts/`):
  the memory-first gate, the memory-context builder, the query pipeline, the grade
  hook and the follow-through hook call the new names.
- **Skills**: `ai-raccoon-memory`, `semantica-knowledge-graph`,
  `code-review-evidence`, `documentation-drift-audit` and the hermes plugin
  references.
- **Generated agent files**: `AGENTS.md`, `CLAUDE.md`, `HERMES.md`,
  `copilot-instructions.md`, `AGENTS.override.md` — updated through the framework's
  own scaffold (`welcome-ai-badger` scaffolder), not by hand, so the source in
  `features/` and the scaffolded copy stay in step.
- **MCP tool index** (`.ai-badger/mcp-tools.json` and
  `features/common/mcp/ai-raccoon/tools.json`): the tool names the index routes by.
- **Docs**: `docs/adr/**`, `docs/reference/**` and the other prose references.

Historical changelog entries under `docs/changelog/` keep the old names on purpose —
they record what shipped at the time.
