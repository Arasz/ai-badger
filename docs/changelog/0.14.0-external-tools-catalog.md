# 0.14.0 — external tools are scaffolded from the catalog

External tools (e.g. code-review-graph) are now auto-scaffolded from a feature
catalog, just like MCP servers, skills, and hooks.

## What changed

- New `features/{common,stack}/external-tools.json` catalog format. The scaffold
  reads common → stacks (last-writer-wins on name) and merges with
  `config.externalTools` (user overrides on conflict).
- `code-review-graph` moved from ai-badger's `config.json` into
  `features/common/external-tools.json` — all repos now get it automatically.
- New `schemas/external-tools.schema.json` for validation.
- `config.externalTools` remains as a user-level override mechanism.

## Consumer impact

Repos that already declare `externalTools` in their `config.json` are unaffected
(user overrides win). Repos without `externalTools` now automatically get catalog
tools injected into CLAUDE.md, HERMES.md, and `.mcp.json`.
