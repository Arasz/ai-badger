# 0.215.0 — change: the smallest lane, still planned, tested and reviewed

**Minor** (additive) · **Date:** 2026-10-23

A new default skill, `change`, for edits with no issue or task behind them: fixing a unit
test, refactoring a method, a rename, a config tweak. It keeps the core of `task` at the
size of the change: plan, review the plan, implement test-first, review the diff. The main
agent runs every phase itself, with no delegation; anything that needs another agent's eyes
escalates to `task`.

## Why

A baseline run without the skill, on a two-line behavior change requested with "no need for
ceremony", wrote the failing test first and bumped VERSION, but skipped the plan, committed
straight to the default branch, and reviewed the diff with one hunk unread because the tool output was
compressed. The skill makes those three steps explicit: a four-line plan whose impact sweep
searches docs, README, VERSION and changelog rules; a branch; and a diff review that reads
every hunk.

## Added

- `features/common/skills/change/SKILL.md` (scope `default`) and its plugin copy under
  `skills/change/`.
- `tests/test_change_skill.py` pins the four phases in order and the rules they carry.
- A `change` row and section in `docs/skills.md`.
