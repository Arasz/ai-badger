# 0.172.6 — MCP hook matchers fire on the real tool names

**Patch** (fixes). 2026-09-24.

## Fixes

Three PostToolUse hooks were wired to MCP tools with a bare tool name as the matcher:
`memory_first_gate_post_hook.py` and `memory_grade_hook.py` on `memory_search`, and
`semantica_export_autosave_hook.py` on `export_graph`. None of them ever ran on Claude Code.
The [hooks reference](https://code.claude.com/docs/en/hooks.md) says a matcher made of
"Only letters, digits, `_`, `-`, spaces, `,`, and `|`" is an "Exact string", and that
"a matcher like `mcp__memory` or `mcp__brave-search` contains only exact-match characters,
so it is compared as an exact string and matches no tool." Claude names the tools
`mcp__ai-raccoon__memory_search` and `mcp__semantica__export_graph`, so the exact string
never matched. The memory-first gate never recorded that memory was consulted, the
follow-through grade never ran, and the Semantica autosave never saved anything.

Copilot missed them too. It anchors a matcher to the whole tool name (`^(?:PATTERN)$`)
and spells MCP tools `<server>-<tool>`.

Both matchers are now one anchored regex per tool:

| Tool | Matcher |
|---|---|
| `memory_search` | `^(mcp__.+__\|.+-)?memory_search$` |
| `export_graph` | `^(mcp__.+__\|.+-)?export_graph$` |

It covers Claude's `mcp__<server>__<tool>` (plugin-scoped servers included) and
Copilot's `<server>-<tool>`. The explicit anchors matter on Claude, whose regex path is
unanchored, so `mcp__ai-raccoon__memory_search_extra` stays out. pi's bridge already
matched MCP names through their bare tail and still does. Hermes has no matcher and
filters by name in its plugin, so it needed no change.

A second bug hid `memory_grade_hook.py`'s other registration. The manifest wires it for
`memory_search` and for `Read|ReadFile`, but `merge_hooks` deduplicated a framework hook
by its script alone, so only the first registration reached `.claude/settings.json`. A
framework hook's identity is now its matcher plus its script. A re-scaffold still removes
a script's registration under a matcher it no longer uses.
