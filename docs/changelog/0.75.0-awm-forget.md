# 0.75.0 — Forgetting a project

`awm.py forget [PATH] [--force]` removes a project's entry from `~/.claude/awm/state.json`.

Per-project state (0.74.0) gave `disable` a smaller job: it flips one entry off and leaves it
in place. Nothing removed one, so the file accumulated an entry for every directory AWM had
ever been enabled in — including worktrees that no longer exist. Nothing broke, since the gate
skips disabled entries, but the file slowly became a record of every directory you had worked
in, which is the content its 0600 mode exists to protect.

It refuses an entry that still holds a live window unless `--force` is passed: forgetting a
running window is likelier to be a slip than an intent. It takes an optional path because the
case that motivated it — a deleted worktree — cannot be `cd`'d into, and it records a
`mode_forgotten` event so removal is as auditable as enabling.
