# 0.87.1 — the shipped plugin copy's shape is the rendered shape

`tooling/sync_plugin_skills.py --check` now verifies more than content: for every shipped skill it
renders the expected copy into a temp directory and compares top-level entry **names** against the
shipped directory. A missing `SKILL.md`, a missing or extra `SKILL.full.md`, or any stray top-level
file is reported (`shape missing …` / `shape unexpected …`) and fails the pre-push gate.

The render is the contract, so shapes the renderer itself would produce are never flagged — the
bootstrap three (welcome-ai-badger, den-refresh, feed-badger, inline body by ADR-0011) and a
source without frontmatter (left alone by `render_into`). Content equality remains the existing
hash-compare; this closes the gap where the shape rule lived only in tests.
