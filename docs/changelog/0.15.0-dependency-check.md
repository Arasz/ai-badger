# 0.15.0 — feature dependencies are checked and installed at scaffold time

Feature dependencies (Python venv, npm packages) are now automatically checked
and installed during scaffold and den-refresh.

## What changed

- New `features/common/dependencies.json` catalog format. Maps features to
  their external package dependencies (ecosystem, package name, venv flag).
- New `schemas/dependencies.schema.json` for validation.
- New `dependency_check.py` script in `welcome-ai-badger/scripts/`. Reads
  `dependencies.json`, creates `.venv` for Python deps, uses `uv pip` when
  available (falls back to pip), and reports install status.
- `scaffold.py` now calls `_check_dependencies()` after hook wiring and before
  config persistence. Results appear in scaffold notes.
- `code-review-graph` is the first declared dependency (Python, venv=true).
- `den-refresh` automatically picks up dependency checking since it delegates
  to `scaffold.py`.

## Consumer impact

Projects scaffolded with `code-review-graph` will now get a `.venv` with the
package installed automatically. The MCP server command in `.mcp.json` should
reference the venv python for reliable execution.
