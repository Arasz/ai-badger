# 0.202.0 — host-only MCP servers get real tags and intents

**Minor** (feature) · **Date:** 2026-10-18

- **Leading-verb tags.** `tool_descriptions.auto_tags` now reads the action from a tool name's
  first `_`/`-` token, matched whole. `get`, `list`, `fetch`, `download`, `export`, `whoami` and
  `describe` give `read`; `query` and `search` give `read, search`; `create`, `update`, `delete`,
  `add`, `upload`, `set` and `patch` give `write`; `cancel`, `pause`, `resume`, `start` and `stop`
  give `run`. A verb inside a word does not count (`budget_report` is not `get`), and no verb
  infers a technology (#171). These verbs led most of the 59 tools the 0.201.0 host-tools smoke left
  `general`.
- **`validate` refuses the placeholder intent.** `TODO: describe what <tool> does` is now one shared
  constant (`tool_descriptions.PLACEHOLDER_INTENT`), and `validate` reports it as `intent is a
  placeholder` instead of passing it for being 10 characters or more. Indexes that already hold
  placeholders now fail `validate`, which is intended.
- **Describe-only catalog.** `features/common/mcp-catalog/<slug>/tools.json` gives real tags and
  intents for servers a host exposes but ai-badger never installs. It holds 85 tools:
  `plugin:figma:figma` 40, `tinyfish` 29, `plugin:huggingface-skills:huggingface-skills` 6,
  `claude.ai Hugging Face` 5, `claude.ai Exa` 3, `plugin:context7:context7` 2.
  - These files carry no `meta.json` and live outside `mcp/`, so the scaffolder, server delivery
    and `index.json` never see them. Only `tool_descriptions.load_catalog` reads them, and an
    installable entry outranks a describe-only one.
  - They are validated against `schemas/mcp-server-tools.schema.json` like the installable
    catalog.
  - Provenance: the figma intents come from
    https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/. The other 45 come from a
    live session: the descriptions the connected servers advertise to Claude Code (2026-10-18).
  - 15 tools whose description could only be inferred from the name are left out on purpose:
    Claude Docs 8, figma `export_video` and `list_file_components_for_code_connect`, 4
    `read_resource`, and glider-trace `trace_build`. `validate` keeps flagging them.
