# 0.131.1 — ai-raccoon-memory relays the code-engine-not-configured warning

**Patch.** Content fix to one existing skill; scaffold output shape unchanged.

`memory_search` results with `kind=code` or `kind=both` can carry a warning:
`code engine not configured — FTS5-only results; run 'ai-raccoon model set code default' …`.
When it is present, the code half of the result is keyword (FTS5) matches only — semantic code hits
are missing, not absent — and nothing in the skill taught an agent to notice.

The `ai-raccoon-memory` skill gains a Gotchas entry: treat the warning as "code results are
keyword-only, not complete"; tell the user once per session, verbatim, to run
`ai-raccoon model set code default` (downloads and activates the default code embedding model,
~187 MB, one-off); do not re-run the search hoping for vector results.

Refs: ai-raccoon issue Arasz/ai-raccoon#422, PR Arasz/ai-raccoon#453; this PR #424.
