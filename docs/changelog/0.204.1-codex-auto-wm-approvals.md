# 0.204.1 — native Codex auto-wm approvals

**Patch** · **Date:** 2026-10-19

## Fixes

- Auto-wm uses Codex PermissionRequest decisions for supported shell approvals instead
  of emitting an unsupported bare PreToolUse allow. PreToolUse no longer logs approvals
  that did not happen. Claude's gate stays unchanged.
- Codex adapters preserve auto-wm scope, expiry and denylist checks and defer patch,
  unknown and malformed requests to normal approval. Prompt context describes the
  supported behavior and uses the installed CLI path.
- Plugin and project hooks use the Codex adapter. An explicit migration checks replacement
  assets, backs up user configuration and removes recognized legacy auto-wm handlers
  while preserving operator hooks.
