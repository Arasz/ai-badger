# 0.214.0 — the framework speaks the ai-raccoon 2.0.0 tool names

**Minor** (the framework follows a breaking client-contract change) · **Date:** 2026-10-21

ai-raccoon 2.0.0 renames its whole MCP tool surface, with **no aliases**: the old names
disappear and the new ones take their place. The framework calls those tools by name — in
the memory-first gate, the query pipeline, the grade hook and the follow-through stash — so
it has to move with them, or it calls tools that no longer exist.

This release renames the tool names in the framework sources and in the generated mirrors,
and renames the host-qualified spellings the hooks match on.

## Changed

- **The tool names.** `memory_search` → `query`; `memory_get` and `code_get` → `get_entry`;
  `memory_list` → `get_index`; `memory_stats` → `get_store_statistics`; `memory_performance`
  → `get_engine_statistics`; `memory_record_followthrough` → `set_memory_usage_record`;
  `memory_record_grade` → `set_query_result_grade`; `memory_write` → `add_memory`;
  `memory_ingest_file` / `memory_ingest_directory` → `ingest_file` / `ingest_directory`;
  `memory_delete` / `memory_delete_context` → `delete_entry` / `delete_context`;
  `memory_share` → `share_memory`; `memory_share_extract` → `trigger_memory_sharing`;
  `memory_promotion_list` / `memory_promotion_discard` → `get_memories_sharing_ranking` /
  `delete_memory_from_ranking`; `memory_sweep` → `trigger_memory_cleanup`; `memory_set_ttl`
  → `set_memory_ttl`; `memory_workspace_*` → `initialize_workspace` /
  `get_workspace_status` / `close_workspace` / `discard_workspace`; `memory_watch_*` →
  `add_watch` / `get_watch_status` / `remove_watch`; `memory_sync` → `sync_to_cloud`;
  `memory_embed_pending` → `embed_deferred_entries`; `project_id_get` /
  `project_id_token_get` → `get_project_id` / `save_project_id_token`.
- **The host-qualified spellings the hooks match on** — `mcp__ai-raccoon__memory_search` →
  `mcp__ai-raccoon__query`, and the `mcp_ai-raccoon_…` and `mcp__ai_raccoon__…` variants.
  A hook that matched the old tail no longer matches anything; one that matched a prefix
  would have matched a tool that does not exist.
- **The helper, test and fixture names** that embedded the old word, in the framework's own
  sources and tests.

## Unchanged on purpose

- **`docs/changelog` and `docs/work`** — historical records of what the framework said at the
  time. Rewriting them would falsify the record.
- **The hermes plugin's `on_memory_write` callback** — its own contract with the plugin
  host, not an ai-raccoon tool name.
- **`memory_get_option` and `memory_list_files`** — not tool names.
