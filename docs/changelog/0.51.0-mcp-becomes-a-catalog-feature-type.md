# 0.51.0 — MCP rebuild step 1 of 8: `mcp` becomes a catalog feature type

Step 1 of the MCP rebuild [ADR-0014](../adr/0014-mcp-support-is-configuration-not-retrieval.md)
describes. **No behaviour change**: the feature type exists, its two schemas exist, and nothing
declares a server yet. `index.json` is byte-identical, because no `features/*/mcp/` directory
has been authored.

## What shipped

- **`mcp` is the eighth entry in `badger_lib.FEATURE_TYPES`.** Discovery rule: any subdir of
  `features/<stack>/mcp/` carrying a `meta.json` is one MCP server, indexed as
  `index.json.stacks.<stack>.mcp[]` with `{name, path}` — `_mcp_items` in `index_build.py`,
  mirroring `_skill_items`.
- **`schemas/stack-mcp.schema.json`** — `features/<stack>/stack-mcp.json`, read at scaffold time
  and deliberately *not* indexed, the same contract `skills.json` already has. Every field of
  `mcp-servers.json` survives into it (`scope`, `env`, `agentOverrides`), with two changes:
  `generate_mcp_json` is renamed `declare` and defaults to **false**, and `targetAgents` is gone
  — it validated against the old schema and was read by no production code.
- **`command` is optional, and required only when `declare` is true.** Naming a server is a
  claim that it is relevant to a stack, which holds however the server arrived; declaring one
  means writing its launch config, which only works on the two routes ai-badger owns.
- `index.schema.json` and `manifest.schema.json` admit the new feature, and `validate.py --all`
  covers the new schema.

## Behaviour worth knowing

**`mcp` is not declinable via `config.exclude`, and drift does not report new mcp items.** Both
sets are the same predicate — a feature type only qualifies when scaffold records a manifest
entry under the item's own index name, or the report can never clear (ADR-0006). An mcp item is
never materialised per-item at all: its content reaches a project through document slots and
generated agent config. ADR-0014's design note expected declinability to come free with the
feature type; it does not, and saying so is cheaper than a permanent drift notice.
