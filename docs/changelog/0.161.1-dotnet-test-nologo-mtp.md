# 0.161.1 — dotnet test --nologo documented as VSTest-only

## What changed

- **Three skill verification snippets no longer pass `--nologo` to `dotnet test`.**
  The flag is VSTest-only: under Microsoft Testing Platform `dotnet test`
  forwards it verbatim to the testhost, which aborts with `Unknown option`
  (zero tests, exit 5; upstream dotnet/sdk#55309). Each snippet now runs bare
  `dotnet test` with a comment stating both versions — VSTest projects may add
  `--nologo`, MTP projects must not. The adjacent `dotnet build --nologo`
  lines are untouched; the flag is valid for build.
- **Patch, no shape change.** No skills added or removed, no slots or paths
  moved — content clarification in existing reference files only.
