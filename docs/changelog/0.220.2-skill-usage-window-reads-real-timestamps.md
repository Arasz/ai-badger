# 0.220.2 — den-refresh's skill-usage window reads real timestamps

**Patch** · **Date:** 2026-11-13

- `skillUsage.window.to` showed a word such as `"contentHash"` and `window.days` was `null`. The
  transcript scan took the first quoted string after any `"timestamp"` text in a line, so a tool
  result holding `["timestamp", "contentHash"]` became the newest timestamp. The scan now reads
  only a `"timestamp": "<ISO date>"` pair, and the window shows the last record's date and the
  day count.
