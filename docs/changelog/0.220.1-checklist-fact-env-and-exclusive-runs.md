# 0.220.1 — run-manual-checklist: facts ignore Git overrides, runs are never replaced

**Patch** · **Date:** 2026-11-13

- `new-run` runs fact commands without `GIT_DIR`-style variables, the same as its Git metadata
  calls. A caller's `GIT_DIR` can no longer make a fact read another repository.
- `new-run` creates the run file exclusively. A run written while the facts ran is refused
  with exit 2 instead of being replaced; `--force` still overwrites.
- `report` validates `findings-against-prior-runs` as a list of non-empty objects or strings,
  and prints a finding object as `key: value` pairs.
