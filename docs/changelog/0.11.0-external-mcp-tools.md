# 0.11.0 — External MCP tool integration

## Added

- **`externalTools` config section** — declare external MCP tools (e.g. code-review-graph) in
  `config.json` with name, package, command, instructions, and optional `generate_mcp_json` flag.
  Scaffold renders their instruction blocks into CLAUDE.md and HERMES.md automatically.
- **`.mcp.json` generation** — scaffold creates `.mcp.json` entries for external tools with
  `generate_mcp_json: true`, using portable commands (no hardcoded venv paths).
- **8 new tests** in `tests/test_external_mcp_tools.py` covering instruction rendering,
  .mcp.json generation, HERMES.md propagation, and schema validation.
- **Schema support** — `config.schema.json` validates `externalTools` array with strict
  field requirements and `additionalProperties: false`.

## Changed

- `CLAUDE.md.tmpl` and `HERMES.md.tmpl` now include `{{EXTERNAL_MCP_INSTRUCTIONS}}` slot
  rendered from `config.json`'s `externalTools` array.
- `_compute_doc_slots()` in scaffold.py now computes external MCP instructions from config.
- `_generate_mcp_json()` method added to `Scaffolder` class for .mcp.json generation.

## Integration

- **code-review-graph** registered as first external tool with `generate_mcp_json: true`.
- CRG MCP server registered in hermes config (30 tools discovered).
- CRG instructions moved from hand-injected root CLAUDE.md to managed scaffold output.
