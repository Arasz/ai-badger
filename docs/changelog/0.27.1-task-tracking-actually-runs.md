# 0.27.1 — task tracking actually runs

## The bug

The `task` skill told the agent to run its tracker as:

```
python3 scripts/task_tracker.py status
```

An agent works from the **project root**. In a scaffolded project the tracker lives at
`.ai-badger/skills/task/scripts/task_tracker.py`, and `scripts/` at the project root is either
something else entirely or nothing at all. In ai-badger's own repo, `scripts/` is the
framework's script directory and has never contained `task_tracker.py`.

So every tracking call — `status`, `start`, `subagent`, `finish`, `grade`, `reattach` — failed
to find its script. Phase 0 and Phase 2 token tracking silently did nothing, in **every**
scaffolded project, for as long as the instruction has been there.

Nothing failed loudly. The task workflow carried on and simply recorded nothing.

## The fix

All six invocations now use the same fully-qualified form every other skill already used:

```
python3 .ai-badger/skills/task/scripts/task_tracker.py status
```

`task` was the only skill using a bare, cwd-relative script path. `mcp-index` was already
correct — its eight invocations name `.ai-badger/skills/mcp-index/scripts/mcp_index.py`.

## Why it survived so long

Nothing checked that a script a SKILL.md tells you to run exists. `tests/test_skill_docs.py`
now does, for every skill in the catalog:

- every `.ai-badger/skills/<skill>/scripts/<x>.py` path in any SKILL.md must name a script the
  catalog actually ships
- no SKILL.md may use a bare cwd-relative `scripts/<x>.py` path, because it resolves against
  wherever the agent happens to be

The second test is the one that would have caught this on the day it was written.

## Also

`.gitignore` now excludes `.claude/worktrees/`. Subagents working in isolated git worktrees
place a full nested checkout there, and it was not ignored — a `git add -A` would have
committed an entire second copy of the repository.

## Upgrading

Re-scaffold (`welcome-ai-badger`, or `den-refresh`) to pick up the corrected SKILL.md. If your
task history looks emptier than the work you remember doing, this is why.
