# 0.76.0 — Hermes becomes an optional common MCP server

ai-badger now recognizes Hermes Agent as a common MCP server and emits its `hermes mcp serve`
configuration when the Hermes CLI is installed. Projects without Hermes keep their existing MCP
configuration unchanged, and stale Hermes entries are removed on a later scaffold without touching
other or user-authored servers.

The catalog documents Hermes's messaging bridge and its ten MCP tools.
