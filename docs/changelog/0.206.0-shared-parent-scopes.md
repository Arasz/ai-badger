# 0.206.0: Shared parent scopes

Collections can select child repositories explicitly and scaffold the union of their
technology stacks. The collection does not discover neighboring repositories or borrow
child identity and configuration. Repository identities remain private to each child.

Removing a member from the collection shrinks the parent's stack union and re-materializes
the remaining children. A child link to a file the parent no longer has is dropped rather
than left dangling, so a smaller membership never strands a child that can no longer be
synced.

The pytest CI lane uses two workers to keep the full suite within the job budget without
overloading its runner.
