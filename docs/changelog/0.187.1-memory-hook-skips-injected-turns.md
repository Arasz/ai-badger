# 0.187.1 — the memory hook no longer treats harness-injected turns as prompts

**Patch** · 2026-10-03

T2 of the data-access plan (`docs/work/2026-10-02-data-access-follow-ups-plan.md`).

## What changed

- The per-prompt memory hook used to treat anything the harness injected as a user prompt. That
  covered task notifications, subagent hand-backs, cross-session messages, idle notices and
  system reminders. It searched them, and in an opted-in session it planned them through
  OpenRouter.
- Now, when a prompt's text starts with one of the `INJECTED_PREFIXES` in `memory_context.py`, the
  hook skips it, even after leading whitespace. `should_enrich` returns `injected-turn` before
  anything is resolved, spawned or sent.
- A user prompt that merely *mentions* one of those markers still enriches. Matching is exact and
  case-sensitive.
- Claude, Copilot and Hermes all go through the same `build()` gate.
