# 0.201.0 — `mcp-index --discover` reads tool names from Claude Code's init event

**Minor** (feature) · **Date:** 2026-10-18

- **Host tools.** `mcp_index.py init|update --discover` now fills what the stdlib client cannot
  reach (servers answering 401/403, `claude.ai <Name>` connectors, servers with no config) from
  Claude Code's own headless init event (`features/common/skills/mcp-index/scripts/host_tools.py`).
  It runs `claude -p --output-format stream-json --verbose --no-session-persistence --settings
  '{"disableAllHooks": true}' /cost` in `--target`, reads up to the `system/init` event, then kills
  the process group, under a 60s deadline (`--host-tools-timeout`). Measured on Claude Code 2.1.302:
  ~5.5s, no model turn (0 API requests, `total_cost_usd: 0`), 0 settings hooks, no transcript. It is
  on by default when `claude` is on PATH (`$MCP_INDEX_CLAUDE` overrides; empty disables);
  `--no-host-tools` turns it off. The host does the authenticating, and no token store is read.
- **What the init event decides.** A server it reports `connected` is the whole truth, so seeded
  tools it lacks go `removed`; names only, so intents come from the catalog or a `TODO` heuristic.
  Any other host status leaves the server's tools as listed and is noted in the report. A direct
  answer wins over the host, approval refusals stay refused, and no unnamed source becomes `absent`.
  Server names map to `mcp__<name>__` prefixes by Claude Code's rule (every character outside
  `[A-Za-z0-9_-]` becomes `_`), and colliding or overlapping prefixes are refused rather than
  guessed.
- **`headersHelper`** (`scripts/headers_helper.py`) runs the way Claude Code runs it: a shell
  command, 10s, cwd by the scope that declares the server, `CLAUDE_CODE_MCP_SERVER_NAME`/`_URL` set,
  credential variables stripped for project and plugin helpers, and project or local helpers only
  in a directory that accepted the trust dialog. Its JSON headers override static `headers`, are
  sent only to that server's URL, and a failing helper fails only that server.
- **Skip report.** 401 (`needs authorization`) and 403 (`forbidden`) are told apart. The
  `WWW-Authenticate` challenge's `resource_metadata` and `scope` are printed, with the fix:
  authenticate the server in Claude Code via `/mcp`, then rerun with host tools on.
