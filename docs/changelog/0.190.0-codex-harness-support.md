# 0.190.0: Codex harness support

**Date:** 2026-10-11

Codex joins the supported harness catalog. Detection recognizes its configuration,
and scaffolding delivers project instructions, discoverable skills, native TOML
personas and project MCP configuration through Codex conventions.

Generated resources preserve user-owned collisions and configuration. Personas
inherit the session model and reasoning settings. Shared pi/Codex projects retain
full instruction context despite Codex's `AGENTS.override.md` precedence.

Local command hook delivery covers explicitly compatible events and tools;
patch guards and transcript accounting remain outside that contract. Project and
hook trust remain operator decisions. Removing Codex from `config.agents` cleans
its owned MCP block, hook handlers and `.agents/skills/` links. See
[Codex support](../codex.md) and [ADR-0038](../adr/0038-codex-harness-delivery.md) for paths, limits and research sources.

Python 3.10 uses the conditional `tomli` dependency for native TOML parsing;
Python 3.11 and later use `tomllib`.
