# 0.221.0 — review-flow: a coordinator-driven code review with a typed flow model

**Minor** · **Date:** 2026-11-18

## New features

- New default skill `review-flow` (ADR-0051). One coordinator moves a pull-request review
  through a typed flow: context, change model, four parallel review lanes, integration, a
  global-scope check, a result file and a publish step. Each judgement is a one-shot worker.
  This release registers the skill; the flow model, scripts and procedure land in the same
  version before it ships.

## Upgrade notes

- No action. The skill is scaffolded with the other default skills on the next `den-refresh`.
