# 0.207.3 — the memory-first gate goes quiet: the memory result is the agent's, not the user's

**Patch** (fixes) · **Date:** 2026-10-20

The memory-first gate denied the first sighting of a search pattern and carried the memory
hits inside the denial reason. Every host renders a denial as a refusal, so the user met a
memory dump where a confirmation belonged: Claude Code raised a permission prompt, Codex a
blocked tool call, pi the reason as the tool result, Hermes a block message. The agent got
its data; the user got a failure that was not a failure.

The gate now keeps the data and drops the noise:

- **Where the host's tool-call seam carries model-side context** (Claude Code, Codex and pi —
  all three speak the Claude envelope, and all three were measured to accept
  `hookSpecificOutput.additionalContext` on `PreToolUse`), the gate **allows** the search and
  hands the memory result to the model. Nothing is denied, nothing is printed, and the host
  keeps its own permission flow.
- **Where the host cannot** (Copilot CLI and Hermes CLI have no documented model-context
  channel on that seam), the gate denies with **one line** — what to search, then to re-run —
  and the agent runs the search itself, so the data is identical on every host.
- When the memory lookup cannot run at all, every host denies with that one line, so the
  agent searches memory itself; nothing is recorded on the gate's behalf.

The payload speaks about text search, not grep:

- `rawGrepInput` is renamed `textSearchInput`, and it now carries **every** searched pattern
  of the call — grep, rg *and* find. A `find` call used to report an empty array, which is
  the bug this release closes; a `rawResultHash` appears only where the gate captured a raw
  output.
- The `get-raw-grep-result` skill and its script become `get-raw-text-search` and
  `get_raw_text_search.py`. The script's flags (`--pattern`, `--pattern-hash`) are unchanged.

The enforcement is unchanged: the memory search still precedes the repo search, and the
searched-pattern store still decides what passes.

**Upgrade.** A consumer's scaffold picks the new hook on the next `den-refresh`. Hosts that
never re-scaffold keep the old deny behaviour — noisier, but correct.
