# 0.54.4 — the matcher answers conversational turns, and now we know how often

Closes [#221](https://github.com/Arasz/ai-badger/issues/221). Advances
[#140](https://github.com/Arasz/ai-badger/issues/140) step 2.

No mechanism is adopted here. That is deliberate: this repository's standing rule
for the matcher is that no technique gets proposed without a measurement, and the
measurement did not exist yet.

## What was wrong

The retrieval hook fires on **every** user prompt, so most of the traffic it sees
is not a request for a tool at all. Two turns in this repository's own telemetry
were answered anyway:

```
"lets wait with #170 for now"  -> playwright:browser_wait_for
"/auto-wm away 8h"             -> code-review-graph:get_suggested_questions_tool
```

The first matched on the word *wait*, in a sentence about deferring a GitHub
issue. The second is a slash command invoking a local skill. In both cases the
correct output is silence.

Nothing measured how often that happened, because every fixture set was
author-written — invented by the person who also wrote the tool descriptions
being matched, which lifts recall for reasons that have nothing to do with the
matcher.

## What changed

**A fourth fixture set, the first drawn from reality.**
`features/common/retrieval/eval/mcp_queries_observed.jsonl` carries 11 fixtures
harvested from this repository's retrieval telemetry: 2 genuine requests and 9
turns addressed to the agent. The negatives cost nothing to label, because for a
conversational turn the expected answer is silence — no judgement call, and none
of the review burden a positive fixture carries.

A third harvested request, `"recommend some MCP tools for indexing the
codebase"`, is deliberately **not** included. Deciding which tools *should* come
back for it is exactly the judgement telemetry cannot make.

**The number.** At the shipped threshold, over that set:

```
recall@1 = 1.000   recall@3 = 1.000   false_fire = 0.222   (2 of 9)
```

**A pinned, falsifiable test.** `tests/test_mcp_retrieval_observed_fixtures.py`
asserts the false-fire set is exactly those two queries. It fails in *both*
directions: a regression adds one, and an improvement must lower the number
deliberately and say so in the same commit.

## The finding that matters: the coverage threshold cannot fix this

The obvious knob is ruled out, by measurement rather than by opinion. The two
false positives score **0.284** and **0.209**. The weakest genuine request in the
same telemetry scores **0.204** — *below both of them*.

| Threshold | False positives firing | Weakest genuine request |
|---|---|---|
| **0.20** (shipped) | 2 | survives |
| 0.21 | 1 | killed |
| 0.30 | 0 | killed |

There is no threshold that removes a false positive without first destroying a
real request. The authored sets had already hinted at this through a negative
coverage margin (−0.201 easy, −0.125 hard); a margin below zero *means* the two
bands overlap. This set makes it concrete.

**What survives as a lead.** Both false positives are ≤4 tokens, and no
conversational turn above four tokens fires — 0.333 false fire in the 0–4 bucket
against 0.000 for everything longer. Query length separates these cases where
coverage does not. That is a lead to measure next, not a mechanism to adopt now.

## Found while measuring: the published numbers had rotted

Re-running the runner over the three existing sets did not reproduce the table in
`docs/retrieval.md`. Three cells had moved:

| Cell | Published | Measured now |
|---|---|---|
| easy recall@1 | 0.930 | 0.907 |
| long recall@1 | 0.938 | 0.969 |
| long false fire | 0.000 | 0.062 |

Nothing in the matcher changed — the **index** did. Every one of these numbers is
a function of a corpus that lives in `.ai-badger/mcp-tools.json` and shifts
whenever a server is added or a description edited. The table is now re-measured
end to end, stamped with the corpus it was taken against (98 tools, 4 servers),
and carries the command to reproduce it.

That section already holds ADR-0004 to the standard that a number nobody can
reproduce is not a measurement. A number that silently *stops* reproducing is no
better, so it is labelled as a reading taken on a date rather than a constant.

## Behaviour changes worth knowing

None. Nothing in the matcher changed — this release adds an instrument and a
number. The matcher still answers those two turns; it is now impossible to do so
without a test noticing.
