# 0.170.0 — the sqlite pair stays opt-in

**Minor** (scaffold-affecting) · 2026-09-11

Corrects 0.169.0's default set: `sqlite-bank-space-diagnosis` and `sqlite-schema-review` return
to `scope: optIn` ([ADR-0029](../adr/0029-sqlite-skills-stay-opt-in.md)), which supersedes
[ADR-0028](../adr/0028-all-catalog-skills-ship-by-default.md) in part. They are specific to a
SQLite-backed project, so a repo with no SQLite database is not handed them unasked. The other
44 common skills stay `default`, and the `config.include` / `config.exclude` mechanism is
untouched.

## Changes

- `scope: default` → `scope: optIn` in the two sqlite `SKILL.md` files.
- `docs/skills.md`: counts now read **44 `default` / 2 `optIn`**; the pair's at-a-glance rows
  say `opt-in` again and their write-ups moved under **Still opt-in**.
- `sync_plugin_skills.py` drops the two from the shipped plugin copy.
- The framework's own `.ai-badger/skills/` mirrors of the pair are removed with the release.

## Upgrade notes

- `config.include.skills` names either one to receive it; a project that already got them under
  0.169.0 keeps its copies, and a refresh leaves them in place.
- No action is required for projects that never asked for them.
