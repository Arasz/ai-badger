# 0.88.4 — the meta-gate sees every gate

`tests/test_every_check_can_fail.py` exists to prove that every check in this repo can fail.
It could not see the biggest one. Its discovery predicate matched `gates/*.py`,
`add_argument("--check")` and a top-level `compare()`; `tooling/validate.py` spells its flag
`--all` and has none of those, so 19 checks were discovered and validate.py was not among them —
while `.github/workflows/pylint.yml` has been running `validate.py --all` in CI all along,
covering five sub-checks.

## The meta-gate now discovers `--all`

`discovered_checks()` reads `add_argument("--all")` as well, and six provocations register the
five sub-checks — no exemptions:

| sub-check | provocation |
|---|---|
| schemas self-check | a shipped schema that is not a valid Draft 2020-12 schema |
| schema coverage (`undecided_schemas`) | a schema no glob points any instance at |
| per-instance validation | a catalog file that fails its own schema |
| `hooks_manifest_agent_gaps` | a hook reaching one agent, nothing recorded for the rest |
| `hooks_manifest_agent_gaps` | a tree whose manifest glob matches no file at all |
| `skills_lint` | a `SKILL.md` that breaks the name grammar |

## Silence is no longer a verdict

`hooks_manifest_agent_gaps` and `undecided_schemas` only printed when they had something to say,
so an empty root and a healthy one produced the same output: nothing. Both now report every run,
and a `features/*/hooks/hooks-manifest.json` glob that matches no file is a violation rather than
an empty list — checking nothing and finding nothing are different answers.

## `skills_lint`: 8 surviving mutants closed

A 27-mutant audit of `skills_lint` left 11 survivors. All are now killed:

- **Rule 1 (name grammar and the 64-char cap).** The only fixture was `BadName`, which fails at
  character 0 — the one case where `fullmatch` and `match` agree. New fixtures use
  `name-With-Caps` and `my_skill`, plus a 65-char name and a 64-char name for the cap boundary.
- **Rule 5 (`Use when`).** Only the word `Use` was pinned. A `"Use this skill to…"` fixture now
  pins `when` too.
- **Rule 9 (Gotchas section *or* note).** `test_no_gotchas_note_accepted_case_insensitive` wrote a
  body containing **both** a `## Gotchas` heading and the note, so it passed on the heading arm and
  never reached the note arm it is named for. Rewritten to carry the note alone.
- **Scope, the worst.** Every fixture, including the real-corpus test, lived under
  `features/common/skills/`. Narrowing the glob to that one stack left 22 tests green while 15 of
  51 shipped skills went unlinted (dotnet 11, hermes 2, claude 1, mcp 1). The glob now lives in
  `skill_files()`, a fixture lints a skill under `features/dotnet/`, and a corpus test compares
  `skill_files()` against an independent glob.
- **Boundaries.** Rules 4, 6 and 7 had no fixture at exactly 1024 chars, 500 lines or a 5,000
  token proxy, so `>` turned `>=` survived in all three.
- **Two beyond the review's list.** Dropping rule 2's empty-name guard, and letting rules 4-5 run
  on an empty description, both survived; each is now pinned by a secondary assertion on the
  violation set rather than on its first element.
- **The dead `-extensions` clause is gone.** `find features -type d -name "*-extensions"` returns
  nothing, so it guarded a shape that does not exist.

## Two stale entries

- `REFERENCES_EXEMPT` was keyed on a line number, `scaffold-documentation:84`. Line 84 of that
  `SKILL.md` had gone blank and the mention had moved to line 73; the corpus was green by luck.
  The key is now `(skill, the mention line's text)`, and a new test fails when an anchor no longer
  resolves. (For the record: this entry is currently inert either way — the line it names carries
  the word "when", so the condition regex accepts it with or without the exemption.)
- `model.schema.json` validated `features/*/agent-instructions/model.json`, which has never
  matched a file. The shipped instance is
  `features/common/templates/agent-instructions/model.template.json`. A new test fails any
  `SCHEMA_INSTANCES` glob that matches nothing.
