# 0.73.2 — Portable MCP scaffolding

Re-scaffolding no longer writes a machine-absolute `cwd` into `.mcp.json`, or preserves one from
an earlier generated entry. The common code-review-graph declaration now uses its installed
`code-review-graph` console script instead of the login-shell-dependent `python3` interpreter.
User-tool path rewriting also probes the executable in commands that include inline arguments.
