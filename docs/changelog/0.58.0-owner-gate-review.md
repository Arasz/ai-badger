# 0.58.0 — the review-form skill is named for what it is

`create-refinement-document` is renamed **`owner-gate-review`**.

The old name described the mechanism — it emits an HTML form. The new name describes the
role: it is the gate a single human owner rules on each decision through, verdict by verdict,
before anything downstream treats a decision as settled. `differential-feature-refactor`, the
skill that invokes it to collect rulings on undefined points, is updated to call it by the new
name.

## What moved

- `features/common/skills/create-refinement-document/` → `features/common/skills/owner-gate-review/`
  (directory, and `name:` in its `SKILL.md` frontmatter).
- The shipped plugin copy at `skills/owner-gate-review/`, regenerated by
  `tooling/sync_plugin_skills.py` — the stale `skills/create-refinement-document/` copy is
  removed rather than left orphaned.
- `engine/badger_lib.SKILL_SCOPES` carries the new key; an undeclared skill name raises
  `UnknownSkillScope`, so this was mandatory, not optional.
- `differential-feature-refactor`'s `related_skills` metadata and its invocation instruction.
- `index.json`, regenerated.

## Breaking

Invoking the skill by its old name, `create-refinement-document`, no longer resolves — there is
no compatibility alias. Anything that names the skill directly (a prompt, a script, a persona's
routing) needs to be updated to `owner-gate-review`. `differential-feature-refactor`'s own
invocation was the only in-repo caller, and it is updated as part of this change.

## What did not move

The document format the skill emits — `# Refinement feedback`, the `<!-- refinement-form: … -->`
provenance marker, the `refinement:<slug>:v1` storage-key prefix, the `<!-- end refinement
feedback -->` terminator — keeps the word "refinement" throughout. That is the vocabulary of
the *artifact* (the generated review document), a separate, stable contract that
`references/result-template.md` and its parser depend on. Renaming the skill does not require
renaming what it produces, and changing those markers would be a format change wearing a rename's
clothes.

The historical `0.54.0` changelog entry that introduced this skill still calls it
`create-refinement-document` — that entry describes what shipped at the time and is left
unchanged. This entry is the record of the rename.
