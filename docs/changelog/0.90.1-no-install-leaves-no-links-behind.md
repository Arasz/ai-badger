# 0.90.1 — `--no-install` leaves no links behind either

0.89.0 stopped `scaffold_freshness_guard` from overwriting the operator's Hermes plugin: the
gate scaffolds a throwaway copy with `--no-install`, and `_install_user_plugins` became a no-op
under that flag. The fix was real, and it was incomplete.

`Scaffolder.run` calls `symlink_hermes_skills` unconditionally. That step writes into
`~/.hermes/skills/<project>/` — one symlink per delivered skill, each pointing at `--target`.
When `--target` is the gate's `tempfile.mkdtemp(prefix="scaffold-freshness-")`, the directory is
removed the moment the gate finishes and every link it just wrote is left pointing at nothing.

This was found in a real tree, not in review. `~/.hermes/skills/ai-badger/` held 27 links; one of
them read:

```
hermes-memory-provider-development ->
  ../../../../../private/var/folders/.../T/scaffold-freshness-h3wuocot/work/.ai-badger/skills/...
```

The `scaffold-freshness-` prefix names the culprit exactly.

## Why the existing test did not catch it

`test_the_scaffolder_hands_no_install_through_to_the_user_scope` asserted
`not (home / ".hermes" / "plugins").exists()` — the path 0.89.0 had just fixed, rather than the
invariant it was defending. `~/.hermes/skills/` was created a few lines later in the same run and
the assertion could not see it. A test written to the fix instead of to the rule passes for as
long as the rule is broken somewhere else.

## What changed

- `Scaffolder.symlink_hermes_skills` returns early when `install` is false.
- The end-to-end test now asserts `not (home / ".hermes").exists()` — the whole directory, with
  the offending paths printed on failure — so the next leak into user-global state fails here
  whichever subdirectory it picks.
- A second test names this specific regression:
  `test_no_install_leaves_no_hermes_skill_links_behind`.

Verified end to end with the gate's own argument list
(`--no-install --skills ""`, `HOME` redirected to a throwaway directory): **14 entries written
under `HOME` before the fix — 11 symlinks and 3 directories — and 0 after.**

Operators who have run the gate should remove any dangling links:

```
find ~/.hermes/skills -maxdepth 2 -type l ! -exec test -e {} \; -print
```
