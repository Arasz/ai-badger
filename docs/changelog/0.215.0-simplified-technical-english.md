# 0.215.0 — agents write to the user in Simplified Technical English

**Minor** (scaffolding adds a skill and a new first invariant to every agent file) · **Date:** 2026-10-23

Agent messages to the user had no writing standard. Responses and reports used slang, contractions,
conditional verbs and long noun clusters, and put warnings after the procedure they applied to.

This release adds a `simplified-technical-english` skill. It adapts the nine sections of the
ASD-STE100 writing rules to user-agent communication. A new invariant of the same name tells every
agent to use the skill when it writes a response or a report. The invariant is the first bullet in
the invariants section of every agent file.

## Added

- **`simplified-technical-english` skill** (default scope). It gives a message shape (result,
  warnings, evidence, decisions, next step) and one rule for each STE section: words, noun clusters,
  verbs, sentences, procedures, descriptions, safety instructions, punctuation, writing practices.
  Code, commands, paths, identifiers and quoted error text stay unchanged.
- **`simplified-technical-english` invariant.**

## Changed

- **Invariant order.** `scaffold.py` renders the invariants in `LEAD_INVARIANTS` before the others.
  The other invariants keep their order.

## Upgrade

Re-scaffold. The skill copies into `.ai-badger/skills/`, and the invariant becomes the first bullet
in `CLAUDE.md`, `HERMES.md`, `AGENTS.override.md`, `AGENTS.md` and `copilot-instructions.md`.
