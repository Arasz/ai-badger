# 0.171.0 — archify: vendored diagram skill, archify-first with a Mermaid fallback

**Minor** — additive. 2026-09-13.

A new default-scope common-stack skill, `archify`, vendors the complete upstream Archify
packet (MIT, pinned at v2.16.0) so any scaffolded project can turn a description, a repository,
or a pasted Mermaid diagram into a validated, self-contained interactive HTML diagram:
architecture, workflow, sequence, data-flow and lifecycle. A new invariant makes Archify the
catalog's default diagram authoring tool; Mermaid remains the fallback.

## New features

- `archify` skill — the 76-file v2.16.0 release packet vendored byte-identical under
  `features/common/skills/archify/`, with an adapted `SKILL.md`, `LICENSE`,
  `THIRD_PARTY_NOTICES.md`, `VENDOR.md` and `vendor.json`. No runtime npm dependencies; Node.js
  18+ is the only requirement. `node bin/archify.mjs doctor` self-checks; `validate` and
  `deliver` are the authoring and acceptance commands.
- `tooling/vendor_archify.py` — offline `--check` verifies the vendored tree against
  `vendor.json` (`MISSING`/`EXTRA`/`CHANGED`); `--revendor <archify.zip> --expect-sha256 <sha>`
  is the explicit maintainer path to a new upstream release, with the expected sha supplied on
  the command line so the manifest can never verify itself.
- `archify-diagrams` invariant — author architecture, workflow, sequence, data-flow and
  lifecycle diagrams with `archify` when it is installed; fall back to Mermaid when Node.js 18+
  or the skill is unavailable, when the diagram must render inline in committed Markdown, or
  when the user asks for Mermaid or text.
- `system` ecosystem in `dependency_check.py` — presence-detected runtime binaries declared in
  `dependencies.json`, reported as a hint when missing and installed only when a `command` is
  declared and `--execute` was passed. The archify entry declares no command, so Node can never
  be auto-installed.
- `docs/adr/0030-vendored-archify-and-diagram-default.md` records the vendoring, the default
  scope, and the fallback policy.

## Changes

- `task` Phase 2 presents an architecture or flow change with `archify`.
- The `documentation` gateway's `scaffold-documentation` and `update-documentation` members ask
  for an `archify` diagram first and name Mermaid as the fallback.
- Catalog counts move to 48 skills / 47 common / 45 default, with the tree glob at 54
  `SKILL.md` files.
- This repo's own `agentDocs` override moves to 264 lines / 17,800 chars: the new invariant
  pushes `HERMES.md` past the previous cap, and the budget's own rule is to raise the override
  for framework-rendered policy a project cannot shorten without declining it.

## Upgrade notes

- No action required: `scope: default` ships the skill to every scaffolded project on the next
  `den-refresh`, and the Claude Code plugin copy lands under `skills/archify/`. A project that
  does not want it declines with `config.exclude.skills: ["archify"]`.
- Diagrams need Node.js 18+ on PATH. Without it the dependency check reports a hint and diagram
  requests fall back to Mermaid; a Node older than 18 is reported as present, and
  `node bin/archify.mjs doctor` is the version-floor check at use time.
- The vendored packet carries upstream's opt-out update check; set
  `ARCHIFY_UPDATE_CHECK_DISABLED=1` to disable it.
