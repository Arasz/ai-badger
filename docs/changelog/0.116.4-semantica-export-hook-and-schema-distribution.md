# 0.116.4 — Semantica Export Hook & Schema Distribution

**Date:** 2026-08-12  
**Type:** Feature / Minor Fix  

## Summary

Builds on Semantica MCP integration with local extraction options, export hook watch bridge (ADR-0019), and self-contained schema/engine distribution.

### What Changed

- **Export Hook & Watch Bridge (ADR-0019)**:
  - `export_semantica_graph.py` atomically writes Semantica in-memory graph to `.ai-raccoon/semantica-graph.json`.
  - Seeded `.ai-raccoon/semantica-graph.json.tmpl` template for project scaffolding.
  - Registered with AiRaccoon `memory_watch_add` for automatic SQLite `memory.db` indexing.
  - Explains structural JSON parsing and cross-session retrieval via AiRaccoon `memory_search`.
- **Extraction Options & Tool Allocation**:
  - Option 2 (Agent-Guided) via `add_entity` + `add_relationship` + `record_decision` recommended for natural language, specs, and architecture decisions.
  - `code-review-graph` MCP tools recommended for code symbol graphs and call hierarchies.
  - Option 1 (Native Local ML via `torch` + `transformers`) documented as optional fallback for bulk text.
- **Scaffold & Den-Refresh Distribution**:
  - Copies `schemas/` and `engine/` into scaffolded `.ai-badger/schemas/` and `.ai-badger/engine/`, eliminating dangling relative `$schema` paths in consumer repos.
  - Ensures Semantica MCP server catalog entry is distributed on `den-refresh`.
- **Testing & Verification**:
  - 41 tests added/updated (`test_semantica_export_hook.py`, `test_semantica_knowledge_graph_skill.py`).
  - All 3,857 tests passing (100% green).
