# 0.61.4 — The tracking-state guard names who wrote

`_real_tracking_state_is_untouched` snapshots `.ai-badger/task-tracking/` around the whole
session and fails if anything changed. Right invariant, wrong evidence: a `*/30` resume cron or
a `poll_limit.py` daemon left over from an earlier session writes into that directory too, and
the fixture attributed it to the suite.

It failed a pre-push lane four times on 2026-08-01, on runs where the suite was clean — twice
confirmed by re-running immediately and getting a green suite with no error. The lost minutes
are not the cost. The cost is that a genuine leak and a passing cron tick produced the same
message, so the learned response becomes "re-run until green" — which is how #222's leak
survived a fixture that was watching for it.

## What changed

The suite marks its own writes, the way #232 marked its own spawns. `save_json` and
`locked_store` append a record — path, pid, `$PYTEST_CURRENT_TEST` — when
`AI_BADGER_REAL_WRITE_LOG` is set and the destination is inside the real checkout. An external
daemon inherits none of that environment, so its writes are unmarked.

The assertion now fires only on marked writes and names the test. Unattributed changes are
printed as a note and do not fail, so the two cases finally read differently.

Both variables are unset outside the suite, and the marker never raises — an unwritable path or
a missing reference is swallowed, because a diagnostic does not get to fail the save it observes.

## The reference is the checkout, not CLAUDE_PROJECT_DIR

The first draft compared against `CLAUDE_PROJECT_DIR`. Tests monkeypatch that freely, so a full
run marked four legitimate writes into pytest tmpdirs and the scratch project — the guard would
have started failing for a new wrong reason. `AI_BADGER_REAL_ROOT` pins it to the repo the
invariant is actually about.

## The gap, stated

Marking covers `save_json` and `locked_store`, which is every route `tracker_lib` writes
tracking state by, and is what #222's leak used. A suite process writing those files through
some other path would now be reported rather than failed. That is a deliberate trade: a guard
that cries wolf is worse than one with a named blind spot.

14 tests added, none changed.
