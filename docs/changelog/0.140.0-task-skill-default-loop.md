# 0.140.0 — Task skill default loop: effort levels, MoE panels, task-ID derivation

**Minor** (additive)

2026-08-28

- **Default loop:** Two effort-level loops (low/high) now govern every task's spine. Low-effort: prepare → analyze → plan → plan review → implementation → review → apply fixes → pr → gates → close → reflect → merge. High-effort adds MoE panels for plan, plan review, and review implementation, plus a dedicated QA test quality & coverage step.
- **Task-ID derivation:** `{repo-alias}-{key}` formula replaces user-supplied IDs. Repo alias is constant per repo; key is 5 words conveying purpose. Derived during the analyze step.
- **Plan packaging:** Plans are split into packages (units of work) and subpackages, with the last package always being the integration package that ensures cross-package integration and test coverage.
- **MoE panels:** Default 3 experts per panel, with at least one different expert between plan authoring, plan review, and implementation review phases.
- **Reflect step:** New Phase 5 step examines memory, semantica, and session history for cross-task learnings after task close.
