# 0.129.1 — Semantica Hook: Guard the Nudge Arm, Stage the CLI Temp Outside `.semantica/`

**Type:** PATCH
**Date:** 2026-08-18

PATCH because nothing shipped gains a surface: two defensive fixes on the 0.129.0 Semantica
session-graph work (PR #419), both found by the code-review gate on that PR.

## The defects

1. **The nudge arm was the only unguarded lazy-sibling access.** `pre_llm_inject_context` called
   `semantica.semantica_indexed(index)` without a `try/except`, unlike every other sibling arm
   (commit, follow-through, autosave). A stale sibling — an install upgraded from before 0.129
   whose `adjust` had not re-shipped `export_semantica_graph.py` — would raise `AttributeError`
   and abort the *entire* pre-LLM context injection for that turn (usage hints, drift notice and
   MCP tool recommendations all lost). Now wrapped, matching the other arms.

2. **The CLI default path still leaked its atomic temp into the watched directory.** `main()`'s
   default target is `.semantica/semantica-graph-<ts>.json`, but it called `export_graph` without
   `temp_dir`, so the `.tmp.<pid>` file landed inside `.semantica/` — the exact `.tmp`-ingestion
   hole the 0.129.0 work fixed on the autosave arm, re-opened on the manual-CLI arm. Now staged in
   `cwd` (same device, outside the watched dir).

## Evidence

Both pinned with a failing test first: `test_nudge_fails_open_on_stale_module` (RED —
`AttributeError` — before the guard, GREEN after) and `test_main_cli_stages_temp_outside_semantica_dir`.
141 tests pass across the touched files; full suite in CI.
