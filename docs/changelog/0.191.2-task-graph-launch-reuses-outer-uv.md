# 0.191.2 — task-graph launch reuses the outer uv

**Patch** (scaffold-affecting) · 2026-10-17

- The generated `task-graph` launch no longer starts its inner server with a bare `uv` name. It uses `$UV` (which `uv run` sets to its own executable), then `shutil.which('uv')`, and otherwise exits with `task-graph: uv not found`. Before, a client that ran `${HOME}/.local/bin/uv` with `~/.local/bin` off PATH (GUI or minimal env) hit `FileNotFoundError` in the nested call and the server never started.
- Existing `.mcp.json`, `.github/mcp.json`, `.pi/mcp.json` and `.codex/config.toml` entries are never rewritten; re-create the `task-graph` entry to pick up the fix.
- Reported by Codex review on Arasz/job-search-ai-assistant#1391.
