# 0.220.3 — a declined MCP server loses its instructions section; ai-badger drops its own Hermes stack

**Patch** · **Date:** 2026-11-13

- A server named in `config.mcp.decline` no longer gets a `## MCP Tools: <name>` section in the
  generated agent files. Before, the decline removed the launch config but every agent file still
  told the agent how to use the refused server.
- This repository no longer scaffolds itself with the `hermes` stack or the `hermes` agent, and
  declines the `hermes` MCP server. `HERMES.md`, `.hermes.md`, the `hermes-agent-author` persona,
  the `hermes-plugin-development` skill and the hook copies only the Hermes adjustment delivered
  are gone from the tree. The `features/hermes/` catalog is unchanged; consumers are not affected.
