# 0.85.0 — Skills corpus conventions: Gotchas, frontmatter, checklists, disclosure conditions

The 23 distributed skills now follow four corpus-wide conventions from the
[opt-skills plan](../work/2026-08-07-opt-skills-plan.md) (PR-1 of the skills-optimization
sequence): one named Gotchas convention, uniform frontmatter metadata, a verification-checklist
convention, and explicit progressive-disclosure conditions on every `references/` mention.

## What changed

- **G1 — one gotchas convention, named `## Gotchas`.** Renamed in place: `auto-wm`'s
  `Common mistakes`, `ai-raccoon-memory`'s `## 6. Pitfalls`, `mcp-index`'s `Common Pitfalls`;
  `differential-feature-refactor`'s and `owner-gate-review`'s `Common Pitfalls — STOP` became
  `## Red flags — STOP`; `migrate-documentation`'s rationalizations table demoted under its
  Red-flags section. `welcome-ai-badger` and `den-refresh` got real Gotchas sections lifted from
  embedded prose (with `Why — see Gotchas.` pointers at the sources), and the other 14 skills
  carry the one-line "No environment-specific gotchas known." note. `task`,
  `commit-reminder`, `prompt-markers` and `feed-badger` get their Gotchas in the follow-up
  individual-improvements PR.
- **G3 — uniform frontmatter.** `version`/`author`/`license`/`platforms` and
  `metadata.hermes.tags`/`related_skills` now sit on all 10 skills that lacked them
  (`auto-wm`, `call-behaviorist`, `commit-reminder`, `create-task-spec`, `den-refresh`,
  `feed-badger`, `maintain-agent-instructions`, `prompt-markers`, `task`, `welcome-ai-badger`).
  `name` and `description` are byte-unchanged everywhere.
- **G6 — verification checklists.** `task`, `commit-reminder`, `migrate-documentation` and
  `update-documentation` now end with a `## Verification Checklist` of concrete, greppable
  checks (before `## Files` where one exists). The other four get theirs in the follow-up PR.
- **G2 — progressive-disclosure conditions.** Every `references/...` mention in a SKILL.md body
  now carries an explicit when/if trigger on the mention line or within its 3-line window
  (`evidence-first-research` uses the I12 wording; `scaffold-documentation`'s freeze-list
  mention conditioned so the plan's checker stays green after the G1 line shifts).

## Behaviour changes worth knowing

- None for consumers: this is content only — no tooling, no hooks, no scripts. Already-scaffolded
  projects pick the new skill bodies up on the next `den-refresh` (the root `skills/` plugin
  copy and this repo's own `.ai-badger/` were regenerated in the same change).
- Frontmatter `version: 1.0.0` is a content marker and is not coupled to the framework
  `VERSION`.
