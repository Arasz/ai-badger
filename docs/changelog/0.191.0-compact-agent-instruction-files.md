# 0.191.0: Compact agent instruction files

**Date:** 2026-10-13

The generated agent files (CLAUDE.md, HERMES.md, AGENTS.md, AGENTS.override.md and
copilot-instructions.md) are about a fifth smaller. No invariant is dropped and the exclude
mechanism is unchanged.

- Each invariant is one line, `- **Title** (`name`) — rule.`. The per-bullet
  `→ .ai-badger/invariants/<name>.md` line is gone; one sentence under the
  `## Non-negotiable invariants` heading says where every rule's full text lives.
- Invariant bullets are joined by a single newline instead of a blank line.
- The prompt-markers section ends in one short paragraph instead of two.
- HERMES.md no longer carries the "Context file discovery" subsection.
- The task-graph MCP block keeps only what an agent acts on: the CLI twin for worktree
  sessions and the Hermes `mcp_servers:` entry.

Run `den-refresh` to regenerate a scaffolded project's agent files.
