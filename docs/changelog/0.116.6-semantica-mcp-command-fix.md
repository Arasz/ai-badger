# 0.116.6 — Semantica MCP Command Alignment

**Type:** MINOR
**Date:** 2026-08-13

## What Changed

### MCP Server Catalog (`semantica`)
- Updated `features/common/stack-mcp.json` `semantica` launch command from `python3 -m semantica.mcp_server` to `semantica mcp start`.
- Updating the launch command to `semantica` allows execution via the virtual environment entry point (`.venv/bin/semantica` or PATH executable) rather than failing on system `python3` when `semantica` is installed in a virtualenv.
- Updated `tests/test_mcp_semantica_catalog.py` and `docs/skills.md` to reflect the updated command assertion.
