# 0.217.1 — limited-mode check-in works on Windows

**Patch** · **Date:** 2026-10-23

Limited-mode check-in ran POSIX hook commands through `cmd.exe` on Windows. It also treated an
inherited `CLAUDE_CODE_CHILD_SESSION` marker as proof that the caller was a subagent, which could
skip a top-level session's check-in.

## Fixed

- Run Windows hook commands through Git Bash. Use `CLAUDE_CODE_GIT_BASH_PATH` when configured.
- Skip check-in only when the caller passes `--subagent`, not when the child-session marker is
  present by itself.

## Upgrade

Re-scaffold projects that use limited mode to update their generated `limited_mode.py` script.
