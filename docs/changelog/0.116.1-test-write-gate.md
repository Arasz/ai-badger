# 0.116.1 — test write gate

Every test file write now routes through a single `_test_write` gate in conftest
that refuses paths inside the real checkouts or the real home directory. A
filesystem observer (`_checkout_snapshot` + session fixture) watches the whole
checkout tree and reports any write that bypassed the gate (production code,
child interpreter, or external daemon). Two tests whose helpers deliberately
write into the real repo (`test_verify_gate._preserved`, `test_stack_mcp_servers`
`_write_mcp_servers`) use raw `Path.write_bytes`/`write_text` with an
explanatory comment — the gate exists to catch accidents, not to block tests
that know what they're doing.
