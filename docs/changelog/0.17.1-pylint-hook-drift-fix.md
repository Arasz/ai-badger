# 0.17.1 — pylint hook + drift hash fix

Pre-commit pylint hook now works without system-level pylint. Drift
detection no longer reports false positives for skills with extensions.

## What changed

- **Pylint hook (#61):** Changed from `language: system` to
  `language: python` with `additional_dependencies`. Pre-commit creates
  its own managed environment with pylint pinned. Added
  `scripts/requirements-dev.txt`. Set `--fail-under=9.5`.
- **Drift hash fix (#60):** `drift.compare()` hashes from the scaffolded
  target (excluding `extensions/`) instead of the framework source,
  matching `scaffold.record()` behavior. Eliminates false drift for
  skills with config-gated extensions.
