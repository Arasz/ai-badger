# 0.134.1 — Path sanitization centralization & Copilot review fixes for #427

**Type:** PATCH
**Date:** 2026-08-23

PATCH because the shipped surface changed (sanitizer centralization, dot-traversal guard, telemetry) without adding new public capabilities.

## What ships

1. **Path segment sanitization unified & strengthened (`sanitize_path_segment`)**:
   - Centralized single-segment sanitization contract: keeps only `[A-Za-z0-9._-]` ASCII characters, replacing everything else with `_`.
   - Traversal dot-segments are explicitly guarded: `.` becomes `_`, `..` becomes `__`.
   - Unified across `features/common/retrieval/context_enrichment.py`, `features/common/skills/ai-raccoon-memory/scripts/memory_first_gate.py`, `features/common/skills/semantica-knowledge-graph/scripts/export_semantica_graph.py`, and `features/common/skills/worktree-agent-isolation/scripts/blast_radius_kill_guard.py`.
   - Backed by extensive TDD suite in `tests/test_path_sanitization.py`.
2. **Misleading telemetry fixed**:
   - `no_prompt` skip debug event was logged even when the Semantica nudge fired on an empty prompt. Now only logs when no output parts were emitted at all.
3. **Plan doc version corrected**:
   - Target version updated from 0.133.0 to 0.134.0.
4. **Gitignore hygiene**:
   - Added `*.DotSettings.user` to `.gitignore`.
