# 0.219.0 — A re-scaffold removes what ai-badger wrote for a retired catalog entry

**Minor** · **Date:** 2026-11-12

A re-scaffold now removes the config entries that ai-badger wrote for an MCP server or a hook that
the catalog retired. ADR-0049 records why
(`docs/adr/0049-scaffold-prunes-catalog-retired-entries.md`).

## Changed

- **Hooks.** A re-scaffold removes a hook entry from `.claude/settings.json` only when ai-badger
  owns it, its skill has no catalog source, and its script is missing from the target. It checks
  every event. A note names each removed script.
