# 0.113.0 — the agent files carry the rule, not the essay

Invariant bodies were inlined whole into `CLAUDE.md`, `HERMES.md`, `.hermes.md` and
`copilot-instructions.md`. Measured across two real projects, they were **52–54% of every one of
those files**, four times over:

| | total | invariants | share |
|---|---|---|---|
| ai-badger | 194 lines | 101 (20 rules) | 52% |
| a 12-stack consumer | 301 lines | 163 (26 rules) | 54% |

Each invariant is now one bullet: its title, the sentence that states the rule, and a link to the
copy under `.ai-badger/invariants/` that carries the rationale. **ai-badger's own `CLAUDE.md` goes
194 → 144 lines**, 13615 → 9631 chars.

## Why not a bare hub

The obvious version — one line pointing at the invariants directory — was rejected on purpose.
`CLAUDE.md` is context an agent always has; a linked file is context it must choose to fetch. For
rules labelled non-negotiable, that trades a guarantee for a hope. The binding sentence stays
inline; only the reasoning moves.

First-paragraph extraction was measured and rejected too: at 83% of the full text it is not a
compression, because most invariants *are* one paragraph. First-sentence is 35%.

## Where the rule is a list, the list stays

`test_release_convention_invariant` caught the first cut throwing away real content. The changelog
invariant reads "Every release — no matter how small — must:" followed by three numbered steps —
truncating at the colon leaves a sentence that says nothing, and the concrete
`docs/changelog/{version}-{slug}.md` convention stopped reaching the agent files entirely. When the
opening block contains a list, the whole block is kept.

## The path-specific list said nothing, twice

It rendered one line per instruction file:

```
- `python.instructions.md` → `.ai-badger/instructions/python.instructions.md`
```

The left column was the basename of the right column — 12–16 lines to say that files exist in a
directory, named after their topics. Meanwhile the source frontmatter carries
`applyTo: '**/*.py'`, the one thing that says *when* to read the file, and the renderer dropped it.
It now renders the glob:

```
- `**/*.py` → `.ai-badger/instructions/python.instructions.md`
```

Same line count, and it finally answers the question the section exists to answer. A file with no
`applyTo` still names itself rather than vanishing.

## MCP sections stopped restating their own servers

A connected MCP server already injects its own description into the agent's context. The
`## MCP Tools:` blocks repeated it, and in ai-raccoon's case also carried one-time operator setup —
CLI enablement, HTTP transport, watchdog timings — that no agent needs on any turn. What survives
is what the server does not say: precedence (`reach for the graph before Grep/Glob/Read`), the
search-first memory protocol, and operational nuance (Hermes read operations work without a running
gateway; sending needs it). 38 lines to 20.

## A relative link in an inlined body is now a validation error

0.112.0 fixed one broken link by hand. `cross-stack references` could not have caught it: it
resolves a path where the file *lives*, and these bodies are read from the consumer's repo root.
`inlined bodies carry no relative links` closes the class — for invariants, instructions, **and**
MCP server bodies, which are inlined the same way and which the first cut of this check missed.
Absolute URLs are allowed, since they survive the move.

Proven against the real defect: restoring 0.112.0's exact link to
`features/dotnet/invariants/clean-architecture-layering.md` fails the gate with exit 1, naming the
file and the path.

## Tests rewritten

Six, each because it asserted the inlined shape:

- `test_invariant_heading_reaches_claude_md` (5 parametrised) — now asserts the title bullet and
  the link, since there is no `### heading` per invariant any more
- five in `test_project_local_invariants` — project-local invariants render as bullets too, linking
  into `.ai-badger/invariants/local/`, where those project-owned files stay
- `test_the_mcp_region_matches_the_bytes_captured_before_the_migration` — the pinned bytes are the
  trimmed text now

`test_release_convention_invariant` was not rewritten. It failed, it was right, and the code
changed to satisfy it.
