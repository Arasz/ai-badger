# 0.210.0 — The memory context never feeds itself

**Patch** (fix) · **Date:** 2026-10-20

A pi session could be driven by its own memory context: turn after turn arrived carrying
nothing but the memory block the previous turn had injected, and the person typed nothing.
Two defects fed it. Both are fixed.

## Fixed

**The prompt hook searched its own block.** The hook that enriches a prompt with this
project's memory has always refused to search a turn the *harness* wrote — `<task-notification>`,
`<agent-message from=…>`, `[SYSTEM NOTIFICATION …]` and the rest. It did not recognise its
own block. A host that renders injected context back into the conversation therefore fed the
hook its own output: the hook read the identifiers inside the block it had just injected,
searched memory for them, and produced a new block whose query was the previous block's
header. The block re-entered, was searched, and the next block arrived.

The block's header is now one constant, `BLOCK_HEADER`, and it is both the first line the
block is written with and an entry in the injected-turn list. A turn that starts with it is
harness-written, and the hook stops there. The guard stays one list — a host that writes
turns of its own adds its prefix there once.

**pi delivered the gate's memory result as a user turn.** The memory-first gate lets a text
search run and hands the model the memory it found. In pi that result travelled as a
follow-up message, which is a user-role message: it occupied the channel the person's own
words use, it read to the model as something the person had said, and it cost an extra model
call.

The result now rides the tool result — the same model-side channel pi's adapter already used
for post-hook context, and one pi persists and re-sends. No message is sent, so the user
channel stays the user's and the search costs no extra call. A call the gate blocks carries
no result forward: a blocked call has no tool result, and nothing it carried may reach a
later one.

## Notes

ADR-0045 records both decisions, the alternatives that were rejected — including the one
that would have hidden the symptom rather than the cause, remembering the injected
identifiers so the repeat search is skipped — and what each choice costs.

The Claude, Copilot and Hermes hosts are unaffected: they already carry the gate's context
on their own model-side seam, and the hook-side fix is host-independent.
