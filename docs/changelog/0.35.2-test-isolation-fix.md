# 0.35.2 — test isolation fix for prompt-markers debug-log tests

Two debug-log tests in `test_user_prompt_hook.py` wrote marker context data to
the real `features/common/skills/prompt-markers/markers-context.json` instead of
`tmp_path`, corrupting the catalog file on every test run.

## What changed

`test_debug_logging_records_fire_event` and
`test_debug_logging_is_noop_when_unavailable` called
`_write_markers_context(hook.MARKERS_CONTEXT_FILE)` — the real project file.
Both now write to `tmp_path / "markers-context.json"` and monkeypatch
`hook.MARKERS_CONTEXT_FILE` to point there, matching the pattern every other
test in the file already uses.

## Behaviour changes worth knowing

None. Test-only fix; no production code changed.
