# 0.196.1 — manual checklist: drop the chmod 000 decoy from the watch catch-up item

**Patch** (fix) · **Date:** 2026-10-18

`ai-raccoon-manual-checklist`'s `watch-catch-up-heals-a-missed-change` item told the tester to
`chmod 000` `node_modules` before checking that its term is never found. An unreadable directory
yields no term whether or not the exclusion works, so that leg of the check could never fail. The
item now leaves `node_modules` readable, so a broken exclusion surfaces as a found term.
