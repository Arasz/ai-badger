# 0.16.0 — plugin-skill-discovery + stack-ignore

Plugin skill discovery restored for Claude Code. Stack-ignore support for
den-refresh false-positive suppression.

## What changed

- **Plugin skill discovery (#55):** Framework skills are now synced into
  `.claude/skills/` so Claude Code discovers them from the plugin. Added
  `scripts/sync_plugin_skills.py` to automate the sync. 8 framework skills
  + 4 code-review-graph skills = 12 discoverable.
- **Stack ignore list (#54):** New `.ai-badger/stack-ignore.json` file lets
  projects suppress false-positive stack detection in den-refresh. Stacks
  listed in `ignore` array are excluded from `newStacks` output.
- **README:** Added "Bundled tools" section with code-review-graph link.
- **Invariant fix:** Removed ai-badger-repo-specific steps (version_sync.py,
  index_build.py) from the generic "Always bump VERSION" invariant.
