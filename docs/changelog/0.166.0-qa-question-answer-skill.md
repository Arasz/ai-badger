# 0.166.0 — qa skill: grounded question-and-answer sessions with a saved summary

**Minor** — additive. 2026-09-08.

A new default-scope common-stack skill, `qa`, for question-and-answer sessions against
user-supplied context: the user invokes `qa {context}` (anything — pasted text, a path,
a topic), asks questions, gets answers grounded in sources, and the session closes with
a summary saved to `docs/qa-sessions/<topic-slug>.md` in the consumer repo.

## New features

- `qa` skill. The flow: accept any context as given (no context — ask for it first,
  never answer ungrounded) → Q&A loop, one analyzed answer per question → close with
  a session summary (main motive, refined questions, structured answers, open questions,
  source links).
- Grounding rule: at least two sources per answer, memory/code leg first, web leg
  second. No web source — the answer carries the literal note
  `couldn't ground in external source` instead of silently dropping the leg or inventing
  one. Per-answer format is `{answer}` followed by `{grounding}`.
- SKILL.md-only, no scripts: grounding and the summary are agent behaviors, not
  deterministic transforms. Slug rule (lowercase, non-alnum to hyphens, ~64 chars) is
  defined in prose; re-running a session for an existing slug overwrites the file.

## Upgrade notes

- No action required: `scope: default` ships the skill to every scaffolded project on the
  next `den-refresh`; the Claude Code plugin copy lands under `skills/qa/`.
- Not the `qa` test-quality persona (delegation personas namespace): the skill carries a
  one-line disambiguation so agents do not confuse the two.
