# 0.35.0 — lefthook summary logging

Every hook invocation now appends a structured line to `logs/lefthook.log` so results are
observable over time without re-running gates.

## What changed

- **`.lefthook/pre-push/verify.sh`**: added `_log_summary()` — appends a timestamped,
  pipe-delimited line to `logs/lefthook.log` for every `pre-push`, `all`, and individual-lane
  run. Format: `YYYY-MM-DD HH:MM:SS | hook_type | lanes | PASS/FAIL | duration`.
- **`.gitignore`**: `logs/` is now ignored (generated log output).
- **`tests/test_verify_gate.py`**: `test_summary_log_is_appended_on_run` — verifies the log
  file is created and the line format is correct.

## Migration

Nothing required. The `logs/` directory is auto-created on first run and gitignored.
