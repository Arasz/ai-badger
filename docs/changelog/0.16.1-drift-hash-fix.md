# 0.16.1 — drift-hash-fix + pylint-cleanup

Drift detection no longer reports false positives for skills with
config-gated extensions. Pylint bootstrap import suppressed.

## What changed

- **Drift hash fix (#60):** `drift.compare()` now hashes from the scaffolded
  target directory (excluding `extensions/`) instead of the framework source.
  Eliminates false drift reports for skills like `task` that have
  config-gated extensions (github, hermes). The `target` parameter is
  threaded through from `den-refresh` and the CLI.
- **Pylint fix:** Added `# pylint: disable=wrong-import-position` to
  `refresh.py`'s bootstrap import of `badger_lib` (same pattern as
  scaffold.py and drift.py).
