# 0.211.0 — instruction-only scaffolds for limited environments

**Minor** — 2026-10-21

## New features

- Add the opt-in `limited-env` stack for environments where project hook registration is not permitted. It delivers the operating constraints as an invariant and removes identifiable ai-badger project hook registrations while preserving unrelated settings.
- Skip Hermes and Pi user-global hook installation when `limited-env` is selected. Existing user-level plugins, administrator hooks, independent agent plugins, and repository execution policy remain outside the stack's control.

## Upgrade notes

Add `limited-env` to `config.stacks` to use the instruction-only guidance. Hook-dependent telemetry and lifecycle features may be unavailable; the invariant describes these limits and does not claim to enforce agent behavior.
