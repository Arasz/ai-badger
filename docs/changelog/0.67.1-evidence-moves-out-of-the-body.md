# 0.67.1 — evidence moves out of the body

A `SKILL.md` body is loaded every turn the skill is under consideration. Two of them carried large
blocks of *measurement* — browser-capability matrices, transcript-format findings — that an agent
reads once, when debugging, and never acts on. That taxes every turn to serve the rare one.

## What moved

**`owner-gate-review`: 190 → 144 lines.** The two verified/unverified matrices (three browser
engines, two measurement passes, four things still unverified) are now
`references/browser-capabilities.md`. The body keeps the four consequences that actually bind the
protocol — the folder is granted once, only Chromium has a picker, `AbortError` stops the chain,
the storage key must be unique per review — and names the file the evidence went to.

**`task`: 189 → 157 lines.** Three measured-prose blocks moved to
`extensions/claude/extension.md`, which already carries Claude-specific mechanics with a
verification date: the 1250-session `cacheEfficiency` / `modelMix` measurement, the 171-transcript
finding about where subagent transcripts live, and the agent-panel `resolvedModel` artefact. The
body keeps the rule — judge a run by its model mix, over main transcript and subagents together —
and points at the numbers.

Nothing is lost. `references/` and `extensions/` both ship with the skill;
`SKILL_EXCLUDE_PATTERNS` does not touch either.

## Not a length rule

`code-review-checklist` is 363 lines — nearly double either of these — and every one of them is
procedure. The rule this enforces is about *shape*, not size: a measurement lives where
measurements live. A skill that needs 400 lines of procedure is allowed to have them.

## Tests

`tests/test_skill_bodies_carry_procedure_not_evidence.py` is new. It matches the verified/
unverified matrix shape across the whole catalog rather than naming the two offenders, so a third
one cannot appear quietly. It also asserts the moved files still contain their specific
measurements — `Chrome 150`, `WellKnownDirectory`, `resolvedModel`, `isSidechain`, `1250`, `171` —
because a move that drops the numbers is a deletion wearing a move's clothes. A final class proves
each matcher can fire and that an ordinary procedure table is *not* caught.

One pre-existing guard caught a real slip during the move:
`test_skill_docs.py::test_each_documented_subcommand_is_reachable` rejected a shortened
`task_tracker.py status` in the replacement prose. A bare script name is not runnable from the
project root; the full path is restored in both files.
