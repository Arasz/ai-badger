# 0.154.0 — quick-task skill: the single-commit fast lane on main

**Minor** — additive. 2026-08-31.

A new default-scope common-stack skill, `quick-task`, for changes small enough to skip the
full `task` pipeline: one focused fix or small feature that fits a single commit pushed
straight to main, with no branch and no PR.

## New features

- `quick-task` skill. The shape a change must fit (all five, or escalate): one sentence, one
  surface, one commit, reversible, no rulings needed. The flow: minimal 3–6 bullet plan →
  implement with new/updated tests → fast gate (touched-surface tests + lint + docs checks
  only — deliberately no full suite/e2e) → one quick focused review BEFORE the push
  (delegated second pair of eyes for auth/money/data-loss/generated contracts) → single
  conventional commit on main, amend-not-fixup → close the loop naming what was NOT tested.
- Escalation triggers are explicit in the skill: discovered breakage outside the touched
  surface, a fix spanning two surfaces, a plan that will not fit six bullets, anything
  stateful.

## Upgrade notes

- No action required: `scope: default` ships the skill to every scaffolded project on the
  next `den-refresh`; the Claude Code plugin copy lands under `skills/quick-task/`.
