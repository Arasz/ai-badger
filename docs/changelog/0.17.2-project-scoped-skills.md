# 0.17.2 — project-scoped skills only

Removed Hermes user-scoped skill symlinks. Skills live only in
`.ai-badger/skills/` (project scope).

## What changed

- **Removed `symlink_hermes_skills()` (#58):** The scaffold no longer
  creates symlinks from `~/.hermes/skills/<project>/` to
  `.ai-badger/skills/`. Skills are project-scoped only. This eliminates
  the stale-copy problem where user-scoped skills diverged after
  den-refresh.
- **Research task #67:** Investigate syncing Hermes learned skills into
  the ai-badger catalog while preserving auto-learning.
