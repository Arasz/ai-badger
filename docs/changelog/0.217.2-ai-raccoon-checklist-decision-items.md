# 0.217.2 — decision recording in the ai-raccoon checklist and its CLI fallback

**Patch** · **Date:** 2026-11-11

The `ai-raccoon-manual-checklist` skill had no items for the project decision graph. Also, through
ai-raccoon 2.6.0, Claude Code rejects the replies of the decision MCP tools after they commit:
the output schema marks null fields as required.

## Added

- Nine `decision-*` items in the checklist template:
  - record and replay
  - version and transition conflicts
  - graph, query and precedents
  - CLI parity and export
  - read-only mode
  - Semantica import
  - unlink history
  - graph bounds
  - the MCP export size cap
- Each item has a refusal or a no-match case.
- A **Decision recording** heading under the skill's Scope.

## Changed

- The ai-raccoon MCP section tells agents not to retry a decision tool that fails the schema
  check. Agents check the write and continue with the `ai-raccoon decisions` CLI.

## Upgrade

Re-scaffold projects on the `ai-raccoon` stack to pick up the new template items and the
CLI fallback.
