# 0.187.2 — the MCP recommender and the fixture harvest skip harness-injected turns too

**Patch** · 2026-10-03

T2b of the data-access plan (`docs/work/2026-10-02-data-access-follow-ups-plan.md`), from T2's
review.

## What changed

- The MCP tool recommender (`context_enrichment_hook.py`) ranked harness-injected turns as if a
  person had typed them: task notifications, subagent hand-backs, cross-session messages and
  system reminders. It recommended tools for them and wrote their text into retrieval telemetry.
- It now loads `memory_context.py` from the sibling `ai-raccoon-memory` skill and uses its
  `injected_turn` check. An injected turn produces no output, and its only telemetry is a `skip`
  record with `reason: injected_turn` and no query. A prompt that starts with
  `<system-reminder>` blocks is ranked on the text after them.
- When the memory skill is not scaffolded, the recommender behaves as before.
- `tooling/fixture_harvest.py` now also drops the four markup-free injected shapes its regex
  missed (`[Cross-session idle notice]`, `[SYSTEM NOTIFICATION`, `Another Claude session sent a
  message:`, `[Subagent hand-back]`). It uses the same `injected_turn` check, so there is still
  one marker list.
- `docs/reference/data-access.md` and the plan now record ai-raccoon as local and approved for
  client data (owner, 2026-10-03). Its memory server, search and embeddings run on the machine,
  so the MCP-binary egress audit (T8) no longer covers it. A configured `memory_sync` target is
  still the one path that leaves the machine.
