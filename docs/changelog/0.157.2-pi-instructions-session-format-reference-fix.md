# 0.157.2 — pi instructions session-format reference fix

## What changed

- **The pi instructions' Token tracking bullet no longer names a `docs/`-prefixed path.**
  The sentence mangled in #449 — "(pi `docs/session-format.md`)" — was ungrammatical and,
  worse, scaffolded projects' docs-consistency gates parse the bare path-shaped string as an
  inbound reference into the *project's* docs tree, where `docs/session-format.md` does not
  exist, and block `git push` on every managed copy. The bullet now reads
  "(pi package docs: `session-format.md`)" — same pointer, no path shape, gate-clean.
