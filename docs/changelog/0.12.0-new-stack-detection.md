# 0.12.0 — new stack detection in den-refresh

## Added

- **`detect_new_stacks()`** in `drift.py` — reuses `detect.py`'s detection logic to find
  stacks that have signals in the target but are missing from config. Filters to stacks
  known by the framework index. Transitively expands `requires`.
- **`newStacks` field** in den-refresh JSON report — lists stacks detectable in the target
  but not in the project's current config. Agent should offer to add them and re-run.
- **`_load_script()`** helper added to `drift.py` for dynamic script loading.
- 4 new tests: finds new stack, empty when complete, ignores unknown stacks, expands requires.

## Changed

- den-refresh `has_drift` now includes `newStacks` — triggers re-scaffold when new stacks
  are detected.
- SKILL.md updated: "Never re-detect" rule now documents the `newStacks` exception.
