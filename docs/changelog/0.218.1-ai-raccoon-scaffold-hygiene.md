# 0.218.1 — ai-raccoon scaffold hygiene

**Patch** · **Date:** 2026-11-11

Three defects left stale ai-raccoon content in consumer repositories after a re-scaffold.

## Fixed

- The `ai-raccoon-manual-checklist` template was behind the copy that ai-raccoon keeps. A
  re-scaffold deleted 18 items there. The template now has them:
  - 13 `typed-*` items for typed Memory/File/Code entries
  - `reserved-shared-target-documents-and-refusals` and
    `reserved-shared-name-registration-refused`
  - `tool-scope-declared-on-the-tool`
  - `renamed-tools-old-names-refused`
  - `decision-tool-replies-match-output-schema`
  - `consistent-live-database-backup`
- Four items use the 2.x vocabulary (`entryType`, typed get, isolated tool install). The skill's
  Scope has headings for upgrade backup, typed entries, memory TTL and the reserved shared target.
- `mcp-index update` retires a catalog-seeded tool that the catalog no longer lists. Before, a
  server that the host lists without tool detail kept its seeded tools active forever. After
  ai-raccoon 2.0 renamed its tools, a consumer index kept 21 pre-2.0 names (`memory_write`,
  `memory_search`, ...) that the server refuses. Now `update` marks such a tool `removed` when
  its `origin` is `catalog` and the listing does not name it. A `manual` entry stays active,
  because the catalog may not cover it. A live listing (`update --discover`) still retires it.
- The scaffold deletes the retired flat hook copies `.ai-badger/hooks/memory_grade_hook.py` and
  `.ai-badger/hooks/memory_grade.py`, and names each one in its notes. No manifest entry records
  these files, so the manifest prune did not see them, and nothing runs them. Before, only the
  Hermes adjustment deleted `memory_grade.py`, and only when `hermes` was in `config.agents`.
  The live hook is `.ai-badger/skills/ai-raccoon-memory/scripts/memory_grade_hook.py`.

## Upgrade

Re-scaffold projects on the `ai-raccoon` stack. Then run `mcp-index update --discover` to retire
the pre-2.0 ai-raccoon tool names, including names curated by hand.
