# 0.53.0 — personas reach Claude Code

**Date:** 2026-07-30

Closes [#190](https://github.com/Arasz/ai-badger/issues/190).

## What was wrong

A scaffolded persona was copied to `.ai-badger/agents/architect.md` and stopped there. Claude
Code loads subagents from `.claude/agents/*.md` and nothing ever wrote that path, so a repo
scaffolded for `claude` had personas the way a library has a book nobody can borrow. Copilot
got `.github/agents/*.agent.md`; `docs/dictionary.md` recorded the Claude cell as a
"custom slash command / subagent persona" that no scaffolder produced.

Shipped and running are different claims, and this was the first one without the second.

## Added

- **`features/claude/adjustments/adjust_agents.py`** — one `.claude/agents/<name>.md` per
  `.ai-badger/agents/<name>.md`, written on every scaffold. Which personas: exactly the set
  already on disk, i.e. the configured stacks' personas minus `config.exclude.personas`. Not
  `personaRouting`, which is empty in most repos and would deliver nothing.

  The transformation parses the persona's own frontmatter, **strips its `---` block**, and
  re-emits only the keys Claude Code documents — `name`, `description`, `tools`,
  `disallowedTools` — followed by the body. An ai-badger-only key is not passed through: the
  re-emitted set is an allowlist, so a file Claude parses never carries a field it does not
  understand.

- **A managed header on the first *body* line.** Claude Code requires frontmatter to start at
  line 1, so the usual header cannot go above the `---`. It goes immediately below the closing
  fence instead, naming `.ai-badger/agents/<name>.md` as the source of truth. A delivered file
  is regenerated in full on every scaffold; `config.exclude.personas` is the opt-out.

- **An ownership guard, lifted from `adjust_skills.py`.** Adjustments run before the manifest
  is rewritten, so the manifest they read is the previous run's record of what ai-badger
  placed. A `.claude/agents/*.md` that is neither recorded there nor carrying our header is the
  user's file: it is left byte-identical and reported by name. `.claude/agents/` is Claude
  Code's own convention and routinely holds hand-written subagents, so a collision there is
  expected, not exceptional.

## Changed

- **`architect` and `code-reviewer` stopped declaring a `tools:` allowlist.** Both carried
  `tools: Glob, Grep, Read, WebFetch, WebSearch, TodoWrite`, which was inert while nothing read
  it and would have gone live the moment delivery started. An allowlist means *only* those, and
  the documentation is explicit that it also removes MCP: "This example uses `tools` to allow
  only Read, Grep, Glob, and Bash. The subagent can't edit files, write files, or use any MCP
  tools." Delivering it would have cost both personas `Bash`, `Skill`, `Agent`, `Write` and
  **every MCP tool** — while `code-reviewer`'s own Step 0 needs `git diff` and this project's
  own `CLAUDE.md` tells agents to prefer the code-review-graph MCP tools over `Grep`.

  Read-only is now expressed as inherit-everything-minus-writes, using the documented
  `disallowedTools` denylist:

  - `code-reviewer` — `disallowedTools: Write, Edit, MultiEdit, NotebookEdit`. It reports
    findings and edits nothing.
  - `architect` — `disallowedTools: Edit, MultiEdit, NotebookEdit`. `Write` stays: its gate 3
    files an ADR, and its scope boundary forbids editing *code*, not authoring a document.

  `disallowedTools` accepting plain built-in tool names — not only `mcp__*` patterns — was
  verified against the documented example before the key shipped, per the project's rule that a
  number or a mechanism you did not see is not evidence.

- **`docs/dictionary.md`** — the Claude persona cell now names `.claude/agents/*.md`, and the
  persona-routing row stops implying a delivery mechanism that did not exist.

- **`docs/getting-started.md`** — the scaffolded-tree listing shows `.claude/agents/*.md`
  beside the Copilot line that was already there.

## Verified

Re-scaffolded this repository against itself, then dispatched `code-reviewer` from its
delivered file as a real subagent. The demo is the acceptance test: a delivered file that
Claude Code refuses to load is indistinguishable, from the outside, from the bug this release
fixes.
