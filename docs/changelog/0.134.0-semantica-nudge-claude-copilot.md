# 0.134.0 — Semantica: once-per-session export nudge for Claude Code and GitHub Copilot

**Type:** MINOR
**Date:** 2026-08-23

MINOR because the context-enrichment hook gains capability across two hosts: `context-enrichment`
now injects the once-per-session Semantica guidance nudge into Claude Code (`UserPromptSubmit`)
and GitHub Copilot (`userPromptSubmitted`), completing the remaining half of issue #418.

## Context

In 0.130.0 (PR #421), Semantica auto-save was wired to Claude Code and Copilot via `semantica_export_autosave_hook.py`
(`PostToolUse` / `postToolUse`). However, the once-per-session guidance nudge was deferred because
unlike Hermes (which runs `ai_badger_hooks.py` in-process with a live memory set), Claude Code and Copilot
invoke their hook scripts as separate subprocesses per user prompt. Without persistent session marker state,
a prompt-time hook would either spam the nudge on every prompt turn or fail to show it at all.

## What ships

1. **Persistent once-per-session marker state** (`features/common/retrieval/context_enrichment.py`):
   - Pure functions `semantica_nudge_marker_path()`, `semantica_nudge_already_shown()`, `record_semantica_nudge_shown()`,
     and `semantica_indexed()`.
   - Markers land under `~/.ai-badger/semantica-nudge/<safe_session_id>` with sanitized session IDs
     supporting both Claude (`session_id`) and Copilot (`sessionId`) payload spellings.
   - Advisory only: missing session IDs or filesystem errors degrade safely without raising or blocking prompts.
2. **Context enrichment integration** (`features/common/skills/mcp-index/scripts/context_enrichment_hook.py`):
   - When Semantica is indexed in `.ai-badger/mcp-tools.json`, the first turn in a session injects the Semantica
     guidance line (`NUDGE_LINE`) into `additionalContext`.
   - When tool recommendations are also present, both the nudge and tool hints are emitted separated by a newline.
   - Subsequent prompts in the same session skip the nudge, preventing prompt wallpaper.
   - Emits nudge even on empty prompts if Semantica is indexed on turn 1.
3. **Skill documentation**:
   - `semantica-knowledge-graph` SKILL.md gotchas updated to reflect all-agent nudge and auto-save support.
