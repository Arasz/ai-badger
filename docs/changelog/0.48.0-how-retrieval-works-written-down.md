# 0.48.0 — how retrieval works, written down

[`docs/retrieval.md`](../retrieval.md) explains the retrieval layer end to end: what the MCP tool
index is for, how one query travels from a user's message to a ranked suggestion or a deliberate
silence, and how to tell which of those two happened.

Documentation only — no behavior changed.

## What it covers

- **Architecture and logic flow**, as diagrams: where `tokenizer.py`, `bm25.py` and
  `mcp_matcher.py` sit relative to the Hermes context-enrichment hook, and the four terminal
  states one query can reach.
- **Why the gate is a coverage ratio, not a score.** BM25 scores are not comparable across
  corpora of different size, so a threshold tuned on one index is meaningless on another. The
  ratio of matched `idf` to total query `idf` is on the same 0–1 scale whatever the corpus size.
- **Why field weights cannot move the false-fire rate**, and the one boundary case where the
  field *set* can.
- **The eval fixture set** — 43 positive queries, 15 that must return nothing — with the current
  numbers including the unflattering ones: recall@1 of 0.907 against a Wilson 95% interval of
  [0.784, 0.963], a false-fire rate of 0.267 in which every false fire is carried by a single
  matched term, a coverage margin of 0.0089, and a mean query↔document token overlap of 0.781
  that says how easy a question this fixture set is asking.
- **Why `gate`, `no_terms` and `absent` are three events and not one silence**, and why the
  near-miss scoring that feeds them is computed only when debug logging is switched on.
- **`AI_BADGER_DEBUG_REDACT`**: what the query field is worth, and why the drop happens inside
  `log_event` at the point of writing rather than in a later pass over the log.

## Why it exists

The layer's own history is the argument for writing it down. Retrieval shipped, was tested,
was scaffolded into place — and runs nowhere on Claude Code, which debug logging surfaced as
501 records containing zero `mcp_retrieval` events. A component that is built, covered and
copied into place but registered nowhere passes every check the pipeline had. The document says
so plainly, in the present tense, and names the open issue (#147) rather than letting a reader
assume the discovery implied a fix.

`docs/index.md` also picks up ADR-0012, which the index had not listed.
