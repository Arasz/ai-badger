# 0.167.1 — model-groups registry stamps ride the release lineage

**Patch** — stamp fix, no scaffold-shape change. 2026-09-08.

The 0.167.0 release bumped `VERSION` without the two `frameworkVersion` stamps the
model-groups tests pin to it, so CI pytest failed on `main` with
`test_real_registry_satisfies_all_invariants` and
`test_shipped_registry_framework_version_equals_version` (`'0.166.0' == '0.167.0'`).

## Fixes

- `features/common/data/model-groups.json` (seed) and `.ai-badger/model-groups.json`
  (scaffolded mirror) stamped `0.167.0` → `0.167.1`, back on the release lineage.
- `version_sync` does not cover these files (same lesson as `cec8c3b1` on PR #480:
  bump the seed, then re-scaffold for the mirror). Because the `v0.167.0` tag was
  already cut, the fix ships as a patch release rather than riding along.
