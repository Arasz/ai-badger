# 0.181.0 — persona `model:` pins become optional: route by level only

**Minor** (scaffold-affecting) · 2026-09-29

An explicit `model:` pin wins over `level:` (G-6 precedence) but bypasses the
`MODEL_ID_PATTERN` validation registry ids get, so a bare alias (`sonnet`, `opus`) resolves
credential-blind to whichever provider advertises it and kills the delegation at spawn —
`No API key found`, then a doomed fallback retry on the session model. The fix that held up:
drop the pins and route by `level:` alone, with tier taste in `.ai-badger/model-groups.json`
(ai-raccoon `e9519ff9`, verified end to end). But the catalog copied every dropped pin back
on the next `den-refresh`, because `scaffold_personas` delivered persona sources verbatim.

## What changed

- `schemas/config.schema.json` gains `personaModelPins` (boolean, default `true`).
- With `personaModelPins: false`, `scaffold_personas` strips the `model:` frontmatter entry
  as each persona lands in `.ai-badger/agents/` — the entry's own lines and nothing else;
  the other keys and the body are preserved exactly. The strip is at the source-of-truth
  write, so the pi and Claude deliveries (`.pi/agents/`, `.claude/agents/`) inherit the
  pin-free shape with no second policy, and Copilot's `.github/agents/` render omits
  `model:` by construction.
- Three tests in `tests/test_persona_model_pins.py`: the strip, the churn itself (a second
  scaffold must not resurrect a dropped pin), and the grandfather default (knob absent and
  the pin lands beside `level:` exactly as before).
- ADR-0033 records the decision and the trade.

## Behaviour changes worth knowing

- **Nothing changes unless you opt in.** The default keeps ADR-0027's dual-key emission
  unchanged.
- **`personaModelPins: false` survives refreshes.** `den-refresh`, re-scaffold and release
  bumps stop re-adding the pins — the knob is the persistent form of "route by level only".
- **A pin-less persona resolves on its `level:` where the host supports that** (the pi reader
  resolves against `.ai-badger/model-groups.json`) and inherits the session model where it
  does not (Claude Code subagents) — the same degrade ADR-0027 records for a lane-less
  persona.
