# 0.212.1 — The memory gate's footer share is a percentage again

**Classification:** Patch
**Date:** 2026-10-22

## Fixes

- **The memory gate's footer segment ends in a percentage.** The segment read
  `[mem 12 9/10]` — a fraction, and a `0/0` whenever the gate had captured nothing, which is
  the common pi case: the gate captures a raw output only for a single standalone shell grep.
  It now reads `[mem 12 90%]`: the searches the gate answered, and the fetched share of the
  captures as a whole percent (`[mem 3 0%]` when the gate captured nothing).

  The vendored pi adapter carries the corrected segment. Canonical source:
  [Arasz/pi-badger-integration](https://github.com/Arasz/pi-badger-integration), vendored with
  `bun publish.ts --ai-badger`.

## Upgrade notes

None: the segment's format changed once (`[mem 12 9/10]` → `[mem 12 90%]`), and nothing else
reads it.
