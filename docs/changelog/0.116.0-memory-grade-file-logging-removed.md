# 0.116.0 — memory-grade file logging removed (metrics will replace it)

The memory-grade feature (`AI_BADGER_MEMORY_GRADE` → `~/.ai-badger/memory-grade/memory-quality.jsonl`)
is removed: per-search file logging is gone from the framework, the Hermes plugin and the
Claude/Copilot PostToolUse hooks. File-based memory-operation telemetry is being re-approached
(metrics), so the feature returns in a different shape later — nothing in this removal is
load-bearing for that decision.

## What changed

- `features/common/skills/ai-raccoon-memory/scripts/memory_grade.py` and
  `memory_grade_hook.py` deleted; `AI_BADGER_MEMORY_GRADE` is inert (the env var, the
  `~/.ai-badger/memory-grade/` files and any stale `memory_grade.py` copies are simply ignored).
- The Hermes plugin (`features/common/hooks/ai_badger_hooks.py`) no longer logs searches or
  surfaces grade asks; the `memory_search` tool-name matcher moved inline
  (`_is_memory_search`) so the memory-first gate keeps working without the module.
- The memory-first gate's consulted marker for Claude/Copilot moved to a dedicated
  `memory_first_gate_post_hook.py` (PostToolUse) — the gate previously borrowed the
  memory-grade PostToolUse entry to record it.
- `adjust_hooks.py` gained `REMOVED_MODULES`: stale `memory_grade.py` copies are deleted from
  every destination (plugin dir, project `.ai-badger/hooks/`, flat legacy plugin root) on the
  next adjust run.
- The `memory-grade` entry is gone from `hooks-manifest.json`/`hooks.json`; the new
  `memory-first-gate-marker` entry names the marker hook.
- `ai-raccoon-memory` skill docs: the grade-hook section and checklist items are gone.

## Why

The 2026-08-11 AiRaccoon diagnostic found the per-tool usage table built from
`memory-operations.jsonl` was hermes-provider-only and easily misread as global, and the
graded-search log had a 12 % grading rate. Owner decision (2026-08-11): remove the file
logging from ai-raccoon and ai-badger now; the replacement approach (metrics) comes later.
The memory-first gate is unaffected and stays.
