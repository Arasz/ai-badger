# 0.54.1 — review forms preserve feedback safely

The decision-collection skills now produce safer and more predictable review forms.

- The refinement workflow names the actual `CONFIG` fields and requires a unique storage key per review.
- Review notes are blockquoted in generated Markdown so a note containing `---` cannot terminate an item early.
- Decision claims are rendered as text rather than interpreted as HTML.
- Download fallback keeps the generated feedback visibly available for manual verification.
- Both skills now include standard authoring metadata, pitfalls, and verification checklists.
- POSIX-only examples are explicitly identified as such.

Added regression coverage for the protocol, escaping, note delimiting, and skill authoring contract.
