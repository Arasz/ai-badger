# v0.140.1 — Comment-hygiene invariant rewrite (2026-08-28)

The `minimal-comments` invariant was rewritten to state a positive, executable rule
about what a doc comment may contain, and to move document references into a dedicated
`<seealso>` section:

- Original: "Keep doc comments to 1-3 lines stating the contract, not the provenance
  or rationale — point at an ADR or spec doc for the 'why' instead of writing an essay
  inline."
- New: "Write a doc comment as the 1-3 line contract an editor shows on hover — what
  the thing is and how to use it — and never let a PR, issue or ticket reference appear
  anywhere in it."

Key differences:
- The rule now governs *what a comment may reference*, not its overall character
- PR/issue/ticket references are banned outright (not relocated to `<seealso>`)
- Document citations are allowed but only inside the format's own references section
- The first sentence survives truncation into CLAUDE.md so the ban reaches every agent
