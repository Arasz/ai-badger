# 0.204.0 — Async raw grep capture

**Classification:** Minor
**Date:** 2026-10-19

## New features

- Capture first-sighting shell `grep` and `rg` output asynchronously, with a pattern-hash handle and JSON retrieval skill.
- Store results in the ai-badger audit database for about two minutes, scoped to the search working directory and bounded to 1 MiB per output stream.

## Changes

- Remove the `# memory-checked` shell comment requirement from the memory-first gate.
