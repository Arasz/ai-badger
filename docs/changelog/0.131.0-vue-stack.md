# 0.131.0 — vue stack

New `vue` stack for Vue 3 + TypeScript projects, modeled on the `react` stack and distilled
from a real scaffolded project:

- `features/vue/stack.json` — detection via `*.vue`; requires `ts` + `node`.
- `features/vue/instructions/vue.instructions.md` — `<script setup>` conventions, typed
  props/emits/models, computed-first derived state, watcher cleanup, router instance-reuse,
  composables, typed provide/inject, Pinia setup stores, accessibility, behavior-focused
  component testing.
- `features/vue/invariants/accessibility-enforced-by-tests.md` — accessibility runs as a
  failing test (axe + Lighthouse gates), not a review checklist item.
- `features/vue/invariants/presentational-components-never-fetch.md` — one-directional
  view → store → API-client data flow.
- `features/vue/personas/frontend-engineer.md` — Vue frontend-engineer persona.

Minor bump: a new stack changes detection behavior and scaffold output.
